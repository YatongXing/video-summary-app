# CR-WP07-A 独立隔离测试报告

执行时间为 2026-11-06 至 2026-11-07（Windows 本地时间）。范围为全新 Docker Desktop Linux 合成实例及发布前验证，正式实例需另行批准。模型使用离线 FakeModel。测试接收器为 Windows 本地文件，使用保留域名的合成账号和生成的短视频。

## 实际执行环境

- 实际配方 `deploy/compose.wp07.yaml` 使用随机独立项目名、显式合成环境文件、私有 PostgreSQL 17 与 RustFS，以及五个新命名卷。Compose 实际检查了同一项目下的资源标签、挂载与端口。Web 仅绑定 `127.0.0.1`，API、数据库和对象存储不发布主机端口。API、两份 Worker 和 Web 实测 UID 为 10001。
- 另建 `vsa-wp07a-test-1cb8b137e6` 独立 Docker-run 测试实例，应用源码只读挂载，用于直连 HTTP、故障注入、实际权限及 PostgreSQL 回归。它仅为测试开放临时回环 API、数据库和存储端口。实际 Compose 配方的端口证据来自上一项。
- Windows 主机运行 Chrome 和短周期巡检。Linux 物理锁回归使用专用命名卷、真实 FFmpeg/FFprobe 后代、独立 PostgreSQL 合成库和 UID 10001。测试未重启旧 manual/WP06 实例或挂载其卷。

## 巡检证据

周期测试配置为 2 秒轮询、3 秒持续故障阈值。Worker 停止的 FAULT 到 CONTINUING 实际间隔为 6.514242 秒，恢复服务后收到 RECOVERED。API、数据库、RustFS 和 Worker 暂停的探测由同一 Windows 主机逐次调用。持久清理故障使用专用合成库中的 BLOCKED 行，清除后观察到恢复。探测预算通过注入子进程超时验证，输出固定 PROBE_DEADLINE 和通知恢复记录。

证据清单为 `docs/baseline/cr-wp07a-testing.json`。Chrome 截图 `docs/baseline/cr-wp07a-desktop.png` 和 `docs/baseline/cr-wp07a-mobile.png` 只含测试项目和合成任务。正式主机目标、通知接收人、真实模型和任何旧资产操作由后续审批决定。
