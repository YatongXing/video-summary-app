## 权限及接口
- 有效 USER/ADMIN 仅正常 owner 路径读取本人摘要、双语 JSON、视频与 Range；其他用户一律拒绝。实时数据库角色必须与发起时 Principal.role 一致，角色变化使在途操作拒绝，重新获取当前身份后可按新身份访问本人。摘要最终复核、视频各 I/O 前后复核、独立删除控制保留。已配置journal的identity运行中丢失/损坏/失配时须复用现有identity_ready拒读503，不重建控制；视频停止后续块。
- 管理元数据页面和 /admin/tasks 永不返回内容，含本人任务；无内容预览入口。明确字段白名单沿用已批准统计字段。
- GET /admin/tasks?task_id=...&limit=20&offset=0 返回原列表数组。省略或空串为全部列表；canonical UUID（大小写不敏感）精确匹配；其他任意文本均按Task ID字面包含匹配；不限制最小字符数、字符集或36字符输入长度，非匹配文本返回空列表；%/_/反斜线不作为通配符。limit 1..100，offset 0..10000，稳定 submitted_at,user_id,id 顺序。只后台全局查询，不搜索正文或文件名；不保留 User ID 筛选（旧 user_id 参数422）。查询事务2秒 statement_timeout；搜索每当前管理员60次/60秒、来源300次/60秒，持久限速独立于登录计数。超限429/Retry-After，超时503，不返回原始错误。
- CR-001 support 请求所有接口为墓碑410，未认证401、错误角色403，mutation保留CSRF；旧consent/purpose保持410。内部request_id/purpose不得转入owner作为跨用户凭证。
- GET /config/public 只返回 {support_email: string|null}，运行时 SUPPORT_EMAIL 配置，未配置/不合法隐藏；不回显其他配置。源码默认空，不硬编码真实邮箱。

## 前端
- USER/ADMIN 我的任务均保留上传/处理/重试/取消/删除/双语摘要/JSON/视频/seek。所有真实状态显示完整服务端Task ID及复制按钮；仅任务名称下显示并复制编号；导入校验通过提示框不显示编号或复制按钮，但仍验证服务端真实id；展开结果沿用同一卡片的Task ID，不重复显示编号及复制按钮；前任务失败不伪造ID。结果成功态真实状态名仍为SUCCEEDED，不新增COMPLETED。
- ADMIN通过“我的任务/任务元数据”明确切换独立场景，默认我的任务；元数据场景卸载个人导入/任务/结果，账号或角色变化重置个人场景。管理元数据仅列表/Task ID搜索/分页；删除原User ID筛选、请求队列及所有内容按钮。移除支持授权组件和专属类型。
- 全站底部从公共配置显示反馈邮箱mailto，无配置不显示；不自动发送邮件。切账号/角色/卸载清理保持。DELETE202只表示接受后台清理。
