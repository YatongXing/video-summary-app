# 质量评估计划 — Video Summary App

**阶段：** Step 1 指标与流程定义；未开始评测。正式质量阈值须待基线评测后确定。

**关联：** [PRD](PRD.md) · [AC](AC.md) · [E2E 测试计划](E2E_TEST_PLAN.md)

## 1. 基线评测集与标注

- 使用 **15 个经授权视频**，由管理员下载到本地做离线评测。
- 初始分布建议每类约 3 个：课程/讲座/演示文稿、编程教程/软件操作、会议/访谈/讨论、视觉信息主导且少语音、音视频歧义或潜在冲突。该分布是建议，不是硬性配额；素材不足须记录实际覆盖与限制，不得虚构样本。
- 每个视频一名标注者，标注关键事件、重要性、参考时间戳；不设第二名独立标注者或独立裁定。报告须披露单人标注局限。
- 保留模型输出、人工参考标注、评测结果和失败案例，便于比较后续模型/提示词版本。
- 15 个样本只支持初步基线和问题发现，不证明所有视频类型的泛化能力。

### 事件匹配规则

- 参考为人工标注的关键事件；系统事件依据核心语义匹配，不要求措辞相同。
- 一条系统事件至多匹配一条参考事件，反之亦然；评测前制定一致的事件粒度指南。
- 分别报告遗漏的参考事件、无参考支持的系统事件及重复事件。

## 2. 指标、分母与缺失数据

| 指标 | 计算方法与报告要求 |
| --- | --- |
| 关键事件覆盖率 | 与摘要正确匹配的参考关键事件数 ÷ 参考关键事件总数。按一对一匹配规则；分母为所有参考事件，遗漏事件仍在分母。参考事件为零则 N/A。另报无依据和重复系统事件。 |
| 事实准确性 | 正确事实陈述数 ÷ 已核查事实陈述总数。将摘要拆成可独立核查的陈述并分类 Correct、Incorrect、Unsupported、Unable to determine；Unable to determine 不算正确。另报严重事实错误数；若报比例，分母为已核查事实陈述总数。严重错误包括主体识别错误、关键行为/结论颠倒、关键数值严重错误、捏造重大事件。 |
| 时间戳误差 | 对已匹配事件取预测与参考时间戳的绝对差，报告中位数及 P90。未匹配项不进误差统计，但须独立报告；无匹配时 N/A。 |
| 时间戳合格率 | 匹配事件中误差不超过预先批准容差的数量 ÷ 全部可匹配事件数。容差尚未确定，报告合格率前须先确定并记录；在此之前只报告时间戳误差中位数及 P90。 |
| 音视频一致性 | 分别检查：音频转录与音频语义分析（分母为有音频证据的已评估音频事件/主张）；视觉分析与视频本身（分母为有视频证据的已评估视觉事件/主张）；融合摘要/事件中的音画矛盾、重要模态遗漏、无依据推断（分母为音画参考证据充分的已评估融合事件/主张）。各类报告错误数及可选错误比例（错误数 ÷ 该类分母）；不适用、无法判定单列。不得合并不同分母。 |
| JSON Schema 合规 | 通过 PRD schema_version 1.0 结构校验且可解析的输出数 ÷ 预期输出总数；中文/英文分报。缺失系统输出不算成功，计入预期输出分母。 |
| 中英文输出质量 | 按语言、按完整性/语义准确性/JSON 结构一致性分别报告符合要求的输出数 ÷ 该语言全部预期输出数；缺失输出计入分母且不算成功。另报检查数、缺失数、不可判定项和失败案例。 |

所有指标报告样本总数、可评估数、分母、缺失/N/A/Unable to determine 数及原因，不得只报无分母百分比。缺失系统输出不得计为成功；无输出时的主张级指标报告缺失输出并注明无可评估主张；无法评估的参考标注或证据不足时记录原因；不得将其判为正确。

## 3. 流程

1. 记录 15 个样本的授权、来源和实际类型分布；不足时注明。
2. 保存输入、模型输出、人工标注、评测结果、失败案例及对应模型/提示词版本。
3. 每个视频仅由一名标注者做事件/重要性/时间戳标注，并记录没有第二人独立复核。
4. 依既定语义匹配和事实分类评测；无法判定或证据不足须标原因，不判成功。
5. 按指标列明每个分母、缺失项和失败案例，分别报告中英文及素材类别。
6. 基线完成后再提出正式质量阈值；在此之前不宣称阈值通过或系统质量达标。

## 4. 评测准备细节（后续执行前补足）

重要性判定指南、事实陈述切分/抽样量表、音视频项目具体编码表和评测责任人属于评测执行准备；时间戳合格率容差及正式质量阈值尚待后续确定。正式质量阈值仅在基线评测后确定。
