# 质量评估计划 — 视频多模态总结应用

**阶段：** Step 1 质量基线；不代表模型或评测已启动。  
**关联：** [PRD](PRD.md) · [AC](AC.md) · [端到端测试计划](E2E_TEST_PLAN.md)

## 评测集

- 至少 30 个经授权视频，由管理员在本地下载、版本化维护并限制访问。
- 覆盖中文/英文语音、讲座、访谈、屏幕教程、产品演示、无声视频、不同清晰度/时长，以及必须依靠视觉理解的事件。
- 每个视频至少人工标注有效时段、主题边界、关键事实、关键视觉事件、不可分析片段和参考时间戳。
- 仍待决定：样本类型/语言配额、标注指南、双人复核要求、标注负责人和门槛批准人。

## 质量门槛

| ID | 指标 | MVP 门槛 |
| --- | --- | --- |
| MQ-01 | 时间线覆盖率 = 有覆盖状态的有效时长 / 有效视频时长 | ≥99% |
| MQ-02 | 章节覆盖率 = 被正确章节概括的重要主题 / 标注重要主题总数 | ≥90% |
| MQ-03 | 关键视觉事件召回率 = 被正确涵盖的仅视觉重要事件 / 标注仅视觉重要事件总数 | ≥85% |
| MQ-04 | 关键事实支持率 = 可由视频证实的抽样要点 / 抽样要点总数 | ≥95% |
| MQ-05 | 时间戳可用率 = 落在标注内容附近的抽样条目 / 抽样条目总数；关键时刻 ±10 秒，章节边界 ±20 秒 | ≥90% |
| MQ-06 | 不当确定性率 = 对未覆盖或受限片段作确定性陈述的条目 / 该类条目 | ≤2% |

结果必须按中文/英文、时长、内容类型和是否依赖视觉理解分组报告。低于门槛时，应定位至工作单元、视频类型或语言，不能隐藏失败结果或仅修改提示词后宣布通过。

## 发布判定

全部功能 AC 通过后再评估冻结集。任何质量门槛未达到，必须停止发布，或由产品负责人书面批准带明确风险说明的受限试运行。
