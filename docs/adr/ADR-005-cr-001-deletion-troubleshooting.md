# ADR-005 删除、内容访问与备份边界

## 决策

- USER 和 ADMIN 通过个人入口读取本人内容。跨用户排障授权及旧目的授权退役，管理员工作台仅提供白名单元数据。旧记录仅保留关闭、审计、清退和恢复撤销能力。
- 删除先阻止读取和迟到发布，再通过独立删除控制、代次及任务锁停止或隔离生产。逐项核验 SQL、对象、派生文件和评测关联，真实清理完成后才标记完成。
- 持久清理采用四态、单版本和全局物理互斥，保留有界重试、危险停止和受审计的部署者诊断。任务及普通日志自创建起保留 30 天，删除审计按事件保留 90 天，未完成控制保留到解决。
- 软件重建资料和业务数据分别管理。应用不创建新的内容备份。历史副本先清点、隔离、核实和审批，并遵守原清除期限。获准恢复须在隔离状态重放删除控制并撤销旧会话、历史授权，账户状态不明时保持关闭。
