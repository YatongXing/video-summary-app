# ADR-003：评测资料与源任务关联并随删除清理

**状态：** Approved（产品负责人已批准）。

## 决策

维护受访问控制保护的反向关联登记，将源任务与评测输入副本、衍生媒体、人工标注、模型输出、评测结果和失败案例关联。源任务删除时，所有可关联的评测资料、缓存和备份都进入相应清理流程；去标识化不自动豁免。关联登记只向执行治理任务所需的角色开放。

删除先限制在线访问并设置删除栅栏，取消排队任务、尽快停止活动任务，再幂等清理资产；失败记录原因并重试，未确认完成不得报成功。迟到模型响应、异步作业、自动重试和备份恢复都不得重建或重新暴露已删数据。恢复备份后重新应用删除控制。

依据：[PRD §7、§9](../PRD.md) 和 [AC-18～20、AC-22](../AC.md) 的删除期限与评测规则；详细设计见[架构文档](../ARCHITECTURE.md)。

## 不变期限与待验证

任务数据及普通任务日志默认从创建起保留 30 天；用户删除后备份最迟 30 天清除；删除审计留 90 天，仅存必要非正文元数据。清理自动重试超过 3 次或启动清理后超过 30 分钟仍未完成时通知管理员；界面提供“一键强制删除”以手动再次推进清理，不能绕过审计或实际完成校验。通知渠道、反向登记完整性、评测基线因删除失效后的标记或重算方式待设计；它们不得放宽既定期限。
