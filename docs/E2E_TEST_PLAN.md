| E2E-07 退款与取消竞态 | 并发触发取消和系统失败，让可审计最终任务状态分别为取消、系统失败及原因无法确定。 | 依最终状态/原因分类；原因无法确定按未知退款；不得重复变更配额。 |

| E2E-09 累计重试与重复请求 | 同一任务提交 20 次已接受的手动/自动重试；尝试第 21 次；重复投递已接受的同一请求。 | 20 次可接受，第 21 次拒绝；手动与自动共用计数；重复投递不重复计数。 |
| E2E-10 冷却阶梯与被拒请求 | 触发同任务多轮冷却并测 1、2、3、4+级；冷却期间提交手动/自动重试；到期后窗口仍含先前记录时再请求。 | 阶梯依次 1/5/15/30 分钟并封顶；级别只在前次冷却到期后再次触发时推进；冷却期拒绝不开始、不计数、不延长；到期仍检查滚动窗口；自动不得绕过。 |
| E2E-11 取消状态竞态 | 分别取消排队、活动处理、已成功任务；重复取消并观察后台重试/结果再生成。 | 排队取消为 `CANCELLED` 且不扣；活动任务请求停止且已扣额不退、无后续重试/再生成；已成功时保留 `SUCCEEDED`；取消终态，重做新建任务；重复请求无副作用。 |

| E2E-13 UTC 日志 | 任务完整运行并跨用户时区查看。 | UTC 保存提交/开始/完成、排队/处理时长、最终状态、失败原因、重试；本地显示转换不改变存储值。 |
| E2E-14 所有者内容与管理员元数据 | 两种角色分别访问本人和他人的内容，检查视频续流、角色变化和退役路径。后台搜索完整 UUID、任意字面子串及通配符字符，清空输入。检查任务卡、结果区、导入提示与反馈配置。 | 本人内容可读，跨用户和已退役入口拒绝。元数据白名单不含内容，字面匹配和清空恢复符合契约，Task ID 仅在规定位置显示，未配置反馈地址时隐藏。 |
| E2E-15 五状态和反馈 | 遍历排队、处理中、成功、失败、取消；确认处理进度展示及成功后的页面行为。 | 用户仅看到 Queued/Processing/Completed/Failed/Cancelled；成功态映射 `SUCCEEDED`，只更新页面、不弹窗；没有额外阶段或 ETA 承诺；失败说明原因及重试资格。 |
| E2E-16 内部校验和 Markdown 下载 | 验证 schema_version、字段类型/限制、顺序、敏感字段排除、空内部事件数组、旧任务兼容；制造可修复及最终无效输出。 | 内部中英文 JSON 可解析，1.0 空事件数组可合法；已存结果以对应语言的 `.md` 下载，只含摘要、章节和 `HH:MM:SS` 时间戳；后端先校验；有效输出可下载；修复用尽后任务失败、不提供无效下载并按系统错误退款。 |
| E2E-B1 DeepSeek 隔离路径 | 以 011 生成成功任务，再在独立实例升级 012。验证开关、提交固定、模拟上传策略及 multipart、临时 URL 与解析头、合成转写与关键帧、超时和删除。 | 旧任务默认 Qwen 且可下载。开启后可选 DeepSeek，合成服务收到对齐证据，双语 Markdown 通过。取消或失败后清理工作区及应用对象，确认无新的自有 OSS 音轨登记。独立验证旧音轨补偿。模拟摘要响应超过 8 秒、通过 `DEEPSEEK_SUMMARY_TIMEOUT_SECONDS` 缩短并耗尽摘要预算，以及等待期间取消、租约失效或维护关闭。每个场景只发一次请求，失去权限后无结果写入。覆盖无音轨、近数字静音、低音量有信号、无词与 ASR 故障，以及长度截断、不完整 JSON、缺语言、无效字段、达到上限但完整结束。验证三档预算和全时长的 SSE JSON Object。在短片和长片测试正常结束、正文发送中断流和缺少结束标记。验证完整终止时的用量，以及断流不发布或重试。验证无效帧号与原始时间映射，校验日志不含模型正文。 |

| E2E-17 中文英文结果 | 对中文/英文语音输入分别生成中文/英文结构化结果，并核对页面结果结构。 | 语言为 zh/en，结构一致且语义完整；页面仅含摘要及带时间戳的章节，支持播放、章节跳播和语言切换；其他输入语言不列入 MVP 测试。 |
| E2E-18 30 天到期和清理 | 为各状态任务和普通任务日志验证从创建起 30 天；模拟仍处理中任务到期；检查任务衍生数据。 | 排队/运行/失败/未完成/成功均遵守保留；普通任务日志按 30 天清理；运行任务安全停止后清理。 |
| E2E-19 删除、故障处置与历史副本 | 删除有关联评测资料的合成任务，注入临时/持续/危险清理故障及Worker竞争；按审核参数检查退避、限频、部署者信号/诊断；历史副本/获准恢复用合成夹具。 | 访问/授权先失效；后台真实清理并验证才完成，其他任务不变；无删除历史/人工产品页，危险删除停止、再推进受控审计；删除审计各事件起90天；不新增内容备份，历史处置仍需专项批准，恢复不复活。 |
| E2E-20 性能统计 | 对 60 分钟视频，在记录环境、负载和样本量的条件下运行成功与失败任务。 | 只对成功任务计算实际开始到成功结束 P90，不计队列时间；失败单报；结果与报告字段完整。该场景验证指标，不预先断言已达到目标。 |
| E2E-21 初始质量评测 | 项目负责人在本地应用界面手动运行 15 个授权视频并记录基线；核对标注、输出、失败/缺失数据和报告。 | 每个视频只有一名标注者；报告披露无独立复核；对成功匹配事件报告时间戳误差中位数、P90及 ±5 秒（含边界）容差内比例，并列明分子/分母；将 ±5 秒标为初始评测容差，不作为整体质量门槛；逐项列 N/A/不可评估原因和失败案例；不声称泛化保证或预设阈值通过。 |
| E2E-22 URL 安全与范围 | 导入合法 HTTPS 直达视频文件；再尝试内网/回环地址、重定向至内网、超限流、含 URL 凭据/查询参数、YouTube/Bilibili 播放页面及需登录/DRM 地址。 | 仅合法且经安全校验的 HTTPS 直达文件经本地导入后按同一媒体规则处理；平台播放页面、非法/危险/不支持路径拒绝；不得向模型传用户原始 URL 的敏感查询参数，日志/导出不泄漏凭据；不绕过访问限制或技术保护。 |

## 执行前待确定与专项规格

已批准的容器/编码组合须先完成兼容性验证；DeepSeek 输出无效时直接失败，定向测试应检查本次尝试只提交一次摘要。实施阶段须为除外部模型推理外的模块编写可重复执行的单元/集成回归测试；外部模型用测试替身，付费调用不属于自动回归测试。

| 非模型模块 | 回归规格 |
| --- | --- |
| 身份、会话和内容权限 | 两角色 owner 内容、跨用户拒绝、元数据白名单及搜索、登录和查询限速、旧入口拒绝、续流门禁。 |
| 本地与 URL 导入 | 两种输入同一 2 小时/2 GB 与编码白名单；损坏文件、伪装 MIME、超限流、回环/内网地址、重定向和 URL 敏感参数不进日志。 |
| 配额和重试 | 6 小时恢复、开始扣额、分类退款及幂等；滚动窗口、20 次累计、自动/手动共用冷却，重复请求不重复计数。 |
| 队列和 Worker | 平手排序、三种获准情形的有限越过、同用户活动名额、全局并发、重复领取、租约失效、重启恢复和被越过任务最终可运行。 |
| 取消与任务状态 | 排队/处理中/成功后的取消竞态，终态不回退，迟到模型结果或自动重试不重建已取消数据。 |
| 输出契约 | 中英文 Markdown 文件名、标题和时间戳，以及内部 1.0 校验、必填字段/类型/顺序、敏感字段排除、无效输出不得标为成功或可下载。 |
| 删除与历史副本 | 关联资产、栅栏/Worker竞争、幂等、限频退避/可发现信号/危险停止/受控再推进、最小审计；无新内容备份，历史能力和获准恢复防复活。 |
| 保留与日志 | 任务和普通任务日志 30 天到期、删除审计按各事件时间 90 天到期，跨时区显示不改变 UTC 期限。 |
