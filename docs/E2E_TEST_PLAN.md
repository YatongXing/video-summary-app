# 端到端测试计划 — Video Summary App

**阶段：** Step 1 测试需求定义；未执行实现或测试。

**关联：** [AC](AC.md) · [质量评估](QUALITY_EVALUATION.md)

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| E2E-01 账户和角色 | 用邮箱/密码注册、退出后再登录，模拟会话失效、免密码自动登录及连续错误密码；在请求中附加管理员角色；部署者创建管理员后登录。 | 账户持久保存、无邮箱验证/审核也可登录；每次新登录须密码，免密码尝试受拒；限速按配置触发且不只依赖 IP；普通账户只能为普通角色，注册不能升级；无管理员自助注册；部署者创建的管理员可登录。 |
| E2E-02 登录、授权与隔离 | 未登录使用核心功能；登录用户未确认权利/处理授权就提交视频，再确认后提交；用户 A 读取用户 B 的任务、视频、摘要和导出。 | 未登录受拒；未确认授权不建任务；确认后可提交；跨用户访问均受拒。 |
| E2E-03 文件大小、容器、编码与时长边界 | 本地与合法直达 URL 分别导入 MP4/MOV/WebM 和 2 GB/2 小时边界样本；测试超限、不支持容器、视频非 H.264/AVC、含音轨但编码非 AAC/MP3、无音轨、损坏及不可解码输入。 | 只接受白名单中且可解码的输入；校验依据实际媒体属性而非扩展名/MIME/URL 后缀；不静默截断；无音轨视频可完成视觉分析并披露无语音；错误可理解、不泄漏内部细节。兼容组合先经技术验证再用于测试。 |
| E2E-04 导入失败与扣额时点 | 中断本地上传、让 URL 下载失败或在校验阶段失败、让有效视频排队后实际开始。 | 未完成上传/导入、开始前失败不扣不退；导入/排队不扣；实际开始只扣一次。 |
| E2E-05 自然恢复跨会话/时区 | 使用到余额低于 3，退出、离线并跨时区，观察 6 小时计时、再使用机会和余额满额。 | 服务端时钟决定恢复；每 6 小时加 1；后续使用不重置活动计时；到 3 停止；余额后来降低才重新开始；界面显示余额和倒计时，不依赖本地时钟。 |
| E2E-06 退款分类、封顶与幂等 | 分别触发用户输入错误、Worker 崩溃/重启、外部模型超时/限流/不可用、未知错误和用户取消；模型超时后模拟第 4 次重试；重复交付同一退款事件并测试余额已满及重试失败。 | 分类退款与 PRD 一致；用户错误/取消不退已扣额，内部/外部/未知退款；Worker 重启不重复扣额，模型超时后的第 4 次重试提示反复失败/可能的 API 费用但不额外扣处理机会；同一失败事件退款只生效一次、只能返还已扣额，未再次扣额的重试失败不造新额度；余额永不超过 3；开始前失败不产生退款。 |
| E2E-07 退款与取消竞态 | 并发触发取消和系统失败，让可审计最终任务状态分别为取消、系统失败及原因无法确定。 | 依最终状态/原因分类；原因无法确定按未知退款；不得重复变更配额。 |
| E2E-08 重试滑动窗口边界 | 首次尝试后在滚动 5 分钟内发起前 4 次、再发起第 5 次；跨越窗口边界重复测试。 | 首次尝试不计；前 4 个重试可接受；第 5 个已接受重试触发第一级冷却；窗口按滚动方式计算。 |
| E2E-09 累计重试与重复请求 | 同一任务提交 20 次已接受的手动/自动重试；尝试第 21 次；重复投递已接受的同一请求。 | 20 次可接受，第 21 次拒绝；手动与自动共用计数；重复投递不重复计数。 |
| E2E-10 冷却阶梯与被拒请求 | 触发同任务多轮冷却并测 1、2、3、4+级；冷却期间提交手动/自动重试；到期后窗口仍含先前记录时再请求。 | 阶梯依次 1/5/15/30 分钟并封顶；级别只在前次冷却到期后再次触发时推进；冷却期拒绝不开始、不计数、不延长；到期仍检查滚动窗口；自动不得绕过。 |
| E2E-11 取消状态竞态 | 分别取消排队、活动处理、已成功任务；重复取消并观察后台重试/结果再生成。 | 排队取消为 `CANCELLED` 且不扣；活动任务请求停止且已扣额不退、无后续重试/再生成；已成功时保留 `SUCCEEDED`；取消终态，重做新建任务；重复请求无副作用。 |
| E2E-12 FIFO、平手和用户并发 | 多用户、同用户多任务及管理员任务通过校验入队，包含相同时间戳；让队首仅因同用户已有活动任务受阻，交错取消和重试。 | 按提交时间、用户 ID、任务 ID 保留原始顺序；仅该阻塞情形可由其他用户最早可运行任务越过，同用户任务不乱序；日志解释阻塞/越过/实际启动；普通用户最多一个活动任务，管理员无默认优先权；总并发服从配置。 |
| E2E-13 UTC 日志 | 任务完整运行并跨用户时区查看。 | UTC 保存提交/开始/完成、排队/处理时长、最终状态、失败原因、重试；本地显示转换不改变存储值。 |
| E2E-14 管理员任务内容授权 | 管理员按用户查看元数据；绕过前端直接请求无授权内容；授予指定任务、目的、范围授权后访问，再撤销并请求相同及其他任务，模拟进行中传输。 | 元数据可见；无授权或已撤销时后端拒绝后续访问并停止可中断传输；授权仅覆盖指定内容；已下载的外部副本无法收回且用户已获提示；审计含管理员/任务/时间/原因/结果且不含正文。 |
| E2E-15 五状态和反馈 | 遍历排队、处理中、成功、失败、取消；确认处理进度展示及成功后的页面行为。 | 用户仅看到 Queued/Processing/Completed/Failed/Cancelled；成功态映射 `SUCCEEDED`，只更新页面、不弹窗；没有额外阶段或 ETA 承诺；失败说明原因及重试资格。 |
| E2E-16 JSON 合规和修复 | 验证 schema_version、字段类型/限制、顺序、敏感字段排除、空事件数组；制造可修复及最终无效输出。 | 中/英文同一 Schema 可解析；空 key_events 可合法；后端先校验；有效输出可下载；修复用尽后任务失败、不提供无效下载并按系统错误退款。 |
| E2E-17 中文英文结果 | 对中文/英文语音输入分别生成中文/英文摘要 JSON，并核对页面结果结构。 | 语言为 zh/en，结构一致且语义完整；页面含总览/要点/章节/关键时刻等；其他输入语言不列入 MVP 测试。 |
| E2E-18 30 天到期和清理 | 为各状态任务和普通任务日志验证从创建起 30 天；模拟仍处理中任务到期；检查任务衍生数据。 | 排队/运行/失败/未完成/成功均遵守保留；普通任务日志按 30 天清理；运行任务安全停止后清理。 |
| E2E-19 删除清理失败和备份 | 删除有关联评测副本/标注/输出/失败案例的任务，注入部分清理失败；分别模拟自动重试第 4 次及启动后超过 30 分钟；管理员后台查看持久告警并手动再次清理；验证备份清除和恢复。 | 即时限制访问；关联资产均纳入清理，失败记录类别/原因/重试状态；两类阈值任一触发即持久告警并在管理员后台可见，管理员操作有权限和审计且不能虚报成功；只在清理完成后报成功；备份最迟删除后 30 天清除，恢复不使删除内容重现；删除审计保留 90 天且无正文。 |
| E2E-20 性能统计 | 对 60 分钟视频，在记录环境、负载和样本量的条件下运行成功与失败任务。 | 只对成功任务计算实际开始到成功结束 P90，不计队列时间；失败单报；结果与报告字段完整。该场景验证指标，不预先断言已达到目标。 |
| E2E-21 初始质量评测 | 项目负责人在本地应用界面手动运行 15 个授权视频并记录基线；核对标注、输出、失败/缺失数据和报告。 | 每个视频只有一名标注者；报告披露无独立复核；对成功匹配事件报告时间戳误差中位数、P90及 ±5 秒（含边界）容差内比例，并列明分子/分母；将 ±5 秒标为初始评测容差，不作为整体质量门槛；逐项列 N/A/不可评估原因和失败案例；不声称泛化保证或预设阈值通过。 |
| E2E-22 URL 安全与范围 | 导入合法 HTTPS 直达视频文件；再尝试内网/回环地址、重定向至内网、超限流、含 URL 凭据/查询参数、YouTube/Bilibili 播放页面及需登录/DRM 地址。 | 仅合法且经安全校验的 HTTPS 直达文件经本地导入后按同一媒体规则处理；平台播放页面、非法/危险/不支持路径拒绝；不得向模型传用户原始 URL 的敏感查询参数，日志/导出不泄漏凭据；不绕过访问限制或技术保护。 |

## 执行前待确定

已批准的容器/编码组合须先完成兼容性验证；JSON 自动修复次数是可配置内部参数。实施阶段须为除外部模型推理外的模块编写可重复执行的单元/集成回归测试；外部模型用测试替身，付费调用不属于自动回归测试。

| 非模型模块 | 实施阶段的回归基线（尚未编写） |
| --- | --- |
| 身份、会话和授权 | 账户注册持久化与再次登录、密码哈希、伪造管理员角色、未登录/跨用户读取、管理员任务级同意及撤销。 |
| 本地与 URL 导入 | 两种输入同一 2 小时/2 GB 与编码白名单；损坏文件、伪装 MIME、超限流、回环/内网地址、重定向和 URL 敏感参数不进日志。 |
| 配额和重试 | 6 小时恢复、开始扣额、分类退款及幂等；滚动窗口、20 次累计、自动/手动共用冷却，重复请求不重复计数。 |
| 队列和 Worker | 平手排序、唯一条件越过、同用户活动名额、全局并发、重复领取、租约失效、重启恢复和被越过任务最终可运行。 |
| 取消与任务状态 | 排队/处理中/成功后的取消竞态，终态不回退，迟到模型结果或自动重试不重建已取消数据。 |
| 输出契约 | 中英文 JSON 1.0 解析、必填字段/类型/顺序、敏感字段排除、无效输出不得标为成功或可下载。 |
| 删除和备份 | 关联评测资产枚举、删除栅栏、清理幂等、>3 次或 >30 分钟通知、管理员手动操作审计、备份恢复后不复活删除数据。 |
| 保留与日志 | 任务和普通任务日志 30 天到期、删除审计 90 天到期，跨时区显示不改变 UTC 期限。 |

此计划是验收及回归测试要求，不是已执行测试报告或现有代码测试覆盖率声明；测试文件要在相应模块实现时编写。
