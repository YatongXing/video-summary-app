# 端到端测试计划 — 视频多模态总结应用

**阶段：** Step 1 测试需求；不代表已开始测试或实现。  
**关联：** [AC](AC.md) · [质量评估](QUALITY_EVALUATION.md)

## 原则

- 使用有权处理的本地视频；URL 不是测试入口。
- 功能验收验证系统行为；冻结评测集用于模型质量，不以单个 E2E 成功替代。
- 管理员维护的本地评测视频不向普通用户公开。

| 场景 | 前置条件与操作 | 通过条件 |
| --- | --- | --- |
| E2E-01 登录与私有性 | 两个普通用户和未登录访客访问任务。 | 访客不可访问；用户 A 不可访问用户 B 的项目。 |
| E2E-13 账户创建策略 | 普通用户通过邮箱/密码注册并登录；检查管理员注册入口，并验证部署者创建的管理员账户。 | 普通账户注册/登录成功；不存在管理员自助注册流程；部署者创建的管理员账户可登录并具有管理员权限。 |
| E2E-02 授权与上传 | 分别不确认、确认授权后提交合格视频。 | 未确认不能建任务；确认后可创建私有任务。 |
| E2E-03 输入校验 | 上传超过 180 分钟、损坏、空文件和合格视频。 | 前三类有具体错误且无无效任务；合格视频入队。 |
| E2E-04 额度恢复 | 普通用户消耗 3 个额度，模拟每满 6 小时；管理员同时提交。 | 普通用户不超过 3 且按 6 小时恢复；管理员不受额度限制。 |
| E2E-05 队列稳定性 | 多用户几乎同时创建任务。 | 记录按进入时间、用户 ID、创建顺序稳定；批准的并发配置被遵守。 |
| E2E-06 处理与性能 | 批量处理代表性 60 分钟合格视频。 | 状态/进度可见；P90 ≤20 分钟；完成不弹窗，仅更新结果。 |
| E2E-07 多模态结果 | 处理中文讲座、英文演示、无声视觉视频。 | 有章节/时间戳；适用时有视觉证据；无声视频不虚构语音。 |
| E2E-08 双语 JSON | 完成支持范围内项目并导出。 | 中文、英文导出都是有效 JSON，结构完整、语言标签正确。 |
| E2E-09 失败与限流 | 制造可恢复失败，5 分钟内重试至少 5 次，累计至 20 次。 | 显示原因；第 5 次触发冷却，后续冷却增加；第 20 次后不能重试。 |
| E2E-10 删除与到期 | 删除一个项目，让另一个达到 30 天。 | 删除/到期项目从历史与结果访问中移除，并进入删除流程。 |
| E2E-11 管理员日志 | 管理员按用户查看日志；普通用户访问相同资源。 | 管理员可筛选；普通用户被拒绝。 |
| E2E-12 URL 排除 | 尝试 YouTube、Bilibili、登录或 DRM URL。 | MVP 无导入入口，也不经替代路径下载或处理。 |

## 执行前待补充

测试环境、账户、并发配置、冷却时间参数、测试视频格式/大小、物理清除验证方式和性能样本量，在架构/实施阶段确定。
