# 验收标准（AC）— Video Summary App

**说明**：AC-01～22 为现行需求级验收定义。CR-002 细项以[测试规格](CR-002_TEST_PLAN.md)为准，实际验证结果由[索引](README.md#最新验收和部署证据)统一导航。

| ID | 验收标准 |
| --- | --- |
| AC-01 身份与角色 | 普通用户可用邮箱/密码注册，账户持久保存且能用已注册信息再次登录；每次新登录或会话失效后重新登录均需密码，不提供免密码自动登录；MVP 无邮箱验证/审核步骤。注册账户默认普通角色，注册参数不能提升权限。管理员仅由部署者手动创建，不开放管理员注册；密码安全哈希存储，不明文保存。注册/登录限速可配置且不得仅依赖 IP。 |
| AC-02 身份、授权与私有任务 | 未登录用户不能用核心功能；上传者须确认具有处理授权才可提交；USER 和 ADMIN 均不能通过个人入口读取或操作他人任务、视频和结果。 |
| AC-03 媒体验证 | 本地与 URL 导入均接受 MP4/MOV，最大 2 GB、最长 2 小时；视频编码 H.264/AVC；如含音轨，编码为 AAC/MP3。无音轨视频可走视觉理解并披露无可用语音。服务端验证实际大小、容器、编码、时长、可解码性；不只依赖扩展名/MIME/URL 后缀。超限/不支持/损坏等输入失败给出可理解说明，终止任务，不静默截断。允许容器/编码组合须经技术验证且不得擅自扩展白名单。 |
| AC-04 扣额时点与自然恢复 | 普通用户初始 3 次；上传/校验/排队不扣，实际开始处理时扣 1 次。同任务重试不另扣。余额低于 3 后每 6 小时恢复 1 次，至 3 停止；进一步使用不重置计时，余额再次低于 3 时重启。退款使余额回到 3 时恢复停止，以后再次低于 3 时重启。服务端为准，倒计时不依赖登录或时区；退款不重置自然恢复计时。 |
| AC-05 退款规则 | 内部错误（含 Worker 崩溃导致失败）、外部模型服务超时/限流/不可用退款；未知原因默认退款并记录；明确用户输入问题或主动取消不退已扣额度。每个符合条件的失败事件最多退款一次；同一退款事件重复处理幂等，且只能返还已扣机会；同任务未再次扣额的重试失败不得重复创造机会，模型超时后第 4 次及之后重试也不另扣处理机会。余额不超过 3。开始前失败无需退款。取消/错误竞态按服务端最终状态及可审计原因判定，无法确定则按未知错误退款。 |
| AC-06 失败可见性 | 预处理失败终止并向用户说明原因；不暴露内部堆栈、凭据、密钥或敏感服务器细节。失败分类、退款结果和重试资格可解释；从第 4 次模型超时重试起提示反复失败和可能的 API 费用，但不另扣处理机会。 |
| AC-07 重试计数 | 首次处理不计重试；滚动 5 分钟内前 4 次重试可接受，第 5 次已接受重试触发冷却；每任务累计最多 20 次已接受重试，第 21 次拒绝。手动/自动重试统一计数；重复投递同一请求不得重复计数。冷却/上限拒绝不计数、不开始处理。 |
| AC-08 冷却阶梯 | 任务的第 1/2/3/4 及后续冷却依次 1/5/15/30 分钟，30 分钟封顶；冷却级别在同任务中不重置，仅前一冷却结束后触发新冷却时推进；新任务从第一级开始。冷却请求不开始处理、不计重试、不延长冷却；冷却结束后仍检查滚动窗口。 |
| AC-09 取消与终态 | 排队取消转为 `CANCELLED` 且不开始处理；处理中取消尽快终止并禁止后续自动重试/重新生成，已扣额度不退。取消为终态，重做须新任务。成功已发生时保留 `SUCCEEDED`，不得被迟到取消覆盖；重复取消无额外副作用。 |
| AC-10 队列与并发 | 校验通过后按提交时间 FIFO；时间相同按用户 ID、任务 ID 排序。队首仅因所属普通用户已有活动任务而受阻时，可启动其他用户最早可运行任务；同用户任务保序，记录阻塞、越过及实际启动顺序。普通用户同时最多 1 个处理中任务，但可提交多个。总并发可配置；管理员无限额度但无默认优先级。 |
| AC-11 状态与时间 | 界面只使用 Queued、Processing、Completed、Failed、Cancelled 五个状态；`SUCCEEDED` 对应 `Completed`。不增加用户可见阶段或承诺精确 ETA。处理进度可见；成功仅更新页面、不弹窗。所有时间 UTC 保存、按需本地显示。任务日志含提交/开始/完成时间、排队/处理时长、最终状态、失败原因和重试记录。 |
| AC-12 处理性能 | 60 分钟视频成功任务实际处理时长 P90 ≤20 分钟，从实际开始至成功结束，不含排队；失败另报且不进入成功样本。报告记录环境、并发/负载和样本量。不得描述为已实现/验证；不设固定可用率或任务成功率门槛。 |
| AC-13 多模态与语言 | 处理流程包括校验、必要预处理、画面/音频分析、时间对齐融合、摘要/关键事件时间戳、输出验证和结果展示。支持中文/英文语音及摘要；其他语言不在 MVP。页面结果含一句话总览、3–7 要点、按时间排序章节、通常 3–10 个关键时刻、可跳转时间戳和局限提示；内容不足时可减少关键时刻并说明原因。 |
| AC-14 JSON 契约 | 导出 JSON 符合 PRD schema_version 1.0：仅含规定的版本、video.filename（无本地路径）、video.duration_seconds、language（zh/en）、summary、按时间排序的 key_events（timestamp_seconds 数字、title、description）。不得含 importance、完整转录、用户标识、存储路径、task/video ID。无关键事件时允许空数组。 |
| AC-15 JSON 成功门槛 | 后端在开放下载前验证必需字段、类型、语言值及事件顺序。有限自动修复/重新生成次数可配置，具体数值待后续配置；修复后仍无效则任务失败且不得下载无效 JSON，按系统错误退款。只有摘要及 JSON 满足最低输出要求才是 `SUCCEEDED`。 |
| AC-16 管理员元数据 | 管理工作台只返回白名单元数据，自己的任务也没有内容操作。Task ID 可精确或按字面部分匹配，非空提交、清空复位；分页、稳定排序、限速及超时以 CR-002 为准。 |
| AC-17 所有者内容与退役入口 | USER 和 ADMIN 经个人入口查看本人摘要、双语 JSON、视频和 Range。跨用户、无会话、角色变化及已删内容按契约拒绝；旧排障请求和旧目的授权 API 无旁路。个人任务名称下只显示一次 Task ID 和复制，导入成功提示不显示；反馈入口仅在配置合法邮箱时显示。 |
| AC-18 保留与到期 | 自任务创建起 30 天保留所有状态的任务数据和普通任务日志；到期仍处理的任务须安全停止/终止后再清理。 |
| AC-19 主动删除 | 所有者删除立即移出列表并禁止访问、同步关闭并清退历史授权记录；停止或隔离 Worker，幂等清理受控内容及关联评测资料，隔离其他任务。移除删除记录/人工清理/备份核验产品入口；临时故障退避且限频重试，持续故障有部署者可发现信号，危险删除停止，受控诊断/再推进有审计；参数/命令先审核。只有实际验证完成才标成功。 |
| AC-20 备份与审计 | 不主动创建应用内容备份，部署避免新增含内容的整库备份/系统快照；历史副本先清点隔离核实再批准清理，保留必要清理和获准恢复防复活，过渡期不放宽原清除期限。删除审计各事件起 90 天且到期清理；未完成作业留必要控制，不算完成。明确应用资产清理边界及无法恢复/介质历史字节/下载/供应商副本限制。 |
| AC-21 URL 边界 | MVP 提供 URL 导入。首轮仅接受经服务端安全校验、合法可直达的 HTTPS 视频文件 URL；阻止本机/内网访问、危险重定向、超限下载及凭据泄露，拒绝平台播放页面。不得绕过 DRM、访问限制或技术保护；YouTube/Bilibili 播放页面集成须另行评估授权路径。 |
| AC-22 质量评测 | 基线集为 15 个授权视频、项目负责人本地下载并通过本地应用界面手动评测、每视频一名标注者且无第二人独立复核；报告披露此限制、指标分母、缺失/不可评估项。对成功匹配事件报告时间戳误差中位数、P90，以及误差在 ±5 秒内（含边界）的匹配事件比例；±5 秒仅为初始评测容差，不是系统整体质量合格门槛。正式质量阈值须待基线后确定。 |

## CR-001 验收矩阵

以下矩阵归档 CR-001 原验收编号和当时的预期。涉及排障授权的场景已由 CR-002 替代，仍有效的删除规则见上方 AC-18～20。原执行结果见 [CR-001 测试规格](archive/cr/CR-001_TEST_PLAN.md) 与历史各包报告。

| ID | 场景 | 验收条件 |
| --- | --- | --- |
| CR-AC-01 | 用户删除已完成任务 | 内容立即不可访问，后台清理对应应用控制内容，验证后才标完成。 |
| CR-AC-02 | 删除正在处理任务 | 停止/隔离 Worker，旧代次和迟到响应不能重建或发布内容。 |
| CR-AC-03 | 存储删除失败 | 记录分类错误，按获批退避和频率上限重试；危险删除停止，不虚报成功。 |
| CR-AC-04 | 普通用户及管理员界面 | 无“删除记录”入口、页面及对应产品查询操作。 |
| CR-AC-05 | 管理员工作台 | 无“清理告警与人工处理”、人工清理或备份核验产品页面/操作。 |
| CR-AC-06 | 管理员自己的任务 | 无需排障请求查看自己双语摘要/JSON/视频，验证所有权，无自身授权申请。 |
| CR-AC-07 | 管理员直接读普通用户内容 | 无当前有效任务级授权时服务端拒绝。 |
| CR-AC-08 | 普通用户创建授权 | 生成UUIDv4排障请求编号，绑定用户/任务/scope/创建与到期时间、关闭信息；编号非凭证，24h。 |
| CR-AC-09 | 重新生成请求 | 旧请求编号立即失效；新UUID请求原子替换、新24h/新时间重排；版本CAS防并发覆盖。 |
| CR-AC-10 | 多任务授权 | 每请求编号仅关联一任务，不跨任务复用；旧ID不追随新请求。 |
| CR-AC-11 | 管理员待处理列表 | 管理员有效列表显示请求编号、用户/任务非敏感信息、范围、时间和派生状态、查看/删除操作。 |
| CR-AC-12 | 输入有效请求编号 | 按有效请求编号只定位单请求；列表与编号入口共享认证/角色/任务/范围/期限检查。 |
| CR-AC-13 | 未授权内容类型 | 摘要允许 zh/en 及对应 JSON 不含视频；仅视频不含摘要/JSON；两者均可。 |
| CR-AC-14 | 到期 | 服务端成功创建记录起满24h立即拒绝，不等归档，管理员不可延长；原任务30天先到也失效。 |
| CR-AC-15 | 用户撤销 | 关闭该次请求后编号及后续读取立即失效，停止可中断续传，源任务保留。 |
| CR-AC-16 | 用户删除任务 | 删任务同步关闭当前请求、设置删除栅栏与必要版本更新，旧ID不能访问；已有job/重放也补齐。 |
| CR-AC-17 | 多条请求 | 按请求创建时间 ASC、ID ASC 稳定排序，不改变视频 Worker 调度。 |
| CR-AC-18 | 管理员删除请求 | 请求移出列表且授权及请求编号立即失效；保留必要无内容审计，不删除用户内容。 |
| CR-AC-19 | 多用户并发 | 多用户并发UUID/归属唯一约束正确，无跨用户错误关联或越权。 |
| CR-AC-20 | 同任务并发重新生成 | 任务行锁+单未关闭约束+support_version/expected_version保证最多一有效请求；REGENERATE同时核expected_request_id；重复/迟到POST409→GET，不隐性续期。 |
| CR-AC-21 | 过期/撤销/替换码 | 过期/关闭/替换编号不定位为有效请求、不读内容，不因重启或归档延迟复活；无需精确重放历史POST。 |
| CR-AC-22 | 删除审计 | 只存最小无内容字段，无可恢复副本或有效凭证；各事件起 90 天到期清除。 |
| CR-AC-23 | 列表权限 | 服务端管理员认证；普通用户不可读管理员列表或他人请求信息，知道UUID不产生权限。 |
| CR-AC-24 | 备份功能移除后的删除 | 仍满足认证/归属、幂等、并发、防迟到发布、受控重试、一致性、诊断、隔离及授权终止。 |

现行部署准入见 [WP07-A 执行清单](CR-WP07A_FORMAL_RUNBOOK.md)。历史 M3、隔离恢复及角色计划见 [WP01 切换回退设计](archive/cr/CR-WP01_CUTOVER_ROLLBACK.md)。
