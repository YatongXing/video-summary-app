# 验收标准（AC）— 视频多模态总结应用

功能验收与模型质量评估分开；质量指标见 [QUALITY_EVALUATION.md](QUALITY_EVALUATION.md)。

| ID | 验收标准 |
| --- | --- |
| AC-F-01 | 未登录者不能创建或访问任务；登录用户必须确认权利/授权后才可提交不超过 180 分钟的合格本地视频。 |
| AC-F-02 | 格式、大小、时长、空文件、损坏或不可读输入不创建无效任务，并显示具体原因。 |
| AC-F-03 | 普通用户额度最多 3 个、每 6 小时恢复 1 个且不超过 3 个；管理员不受额度限制。 |
| AC-F-04 | 多用户同时提交时，队列按进入时间、用户 ID、任务创建顺序稳定排序；实现必须记录并遵守批准的并发配置。 |
| AC-F-05 | 用户只能访问自己的媒体、结果和历史；管理员可按用户查看处理日志；普通用户不能查看他人或管理员日志。 |
| AC-F-06 | 状态包括已接收、排队中、分析中、生成与校验中、已完成、失败、等待重试；刷新/重新登录后不丢失。 |
| AC-F-07 | 代表性性能测试中，60 分钟合格视频端到端 P90 ≤20 分钟；页面显示进度与预计/目标时长；成功不弹窗，只更新页面。 |
| AC-F-08 | 失败显示原因和可否重试；5 分钟内第 5 次及以后重试受冷却，后续突发冷却增加；第 20 次用户重试后不可再重试。 |
| AC-F-09 | 成功结果含一个总览、3–7 要点、按时间排序章节、关键时刻、时间戳和适用局限；适用时至少引用一项关键视觉信息。 |
| AC-F-10 | 仅承诺中文/英文语音输入；可导出结构完整的中文 JSON 与英文 JSON。 |
| AC-F-11 | 删除或 30 天到期后，项目从用户历史及结果访问中移除，并进入批准的删除流程。 |
| AC-F-12 | MVP 无 URL 导入入口；测试不以规避平台权限、登录、付费或 DRM 限制的方式输入视频。 |
