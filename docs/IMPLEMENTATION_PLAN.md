## Agent 派发与交接规则

- **主 Agent：** 维护任务依赖与接口约定，分配互不重叠的文件范围，审查实现和证据，决定是否满足 AC；测试通过不自动验收。
- **编码 Sub-agent：** 只修改分配模块，交付变更摘要、数据/状态迁移影响和模块测试；不自行扩大需求、调用付费 API 或提交/推送。
- **测试 Sub-agent：** 独立从 AC/E2E 设计边界、并发和故障用例，必要时复现问题；不与编码 Agent 同时编辑同一文件。认证授权、配额、队列、取消、删除和备份恢复必须独立审查。
- **每次派发格式：** 输入文档与任务 ID、负责路径、接口/数据契约、明确不做的事项、AC/E2E 引用、交付与测试证据。主 Agent 先锁定共享接口，再让互不冲突的任务并行。

测试 Sub-agent 已独立核对 AC/E2E/ADR，建议把验证分为以下六包；各包在对应编码工作完成后提供执行证据，主 Agent 再审核：

| 测试包 | 对应实现与验收 | 独立验证重点 |
| --- | --- | --- |
| T1 身份与授权 | S3-03/09历史 + CR-WP02/03/06 | 保留隔离；新增所有者、码/范围/24h、替换/撤销/请求删除、迁移/旧API拒绝，见CR测试规格。 |
| T2 媒体与 URL | S3-04；AC-03/21 | 真实媒体属性、无音轨/损坏、HTTPS 直达、回环/内网与重定向、超限和 URL 凭据；使用本地受控媒体服务。 |
| T3 调度、额度、重试和取消 | S3-05/06；AC-04～10 | 假时钟覆盖 6 小时恢复、滚动 5 分钟、20 次上限及冷却；双 Worker、旧租约、重复扣退、ADR-002 越过；高风险合并门槛。 |

这些测试使用假时钟、假模型、受控媒体服务、PostgreSQL 集成环境和 Worker 故障注入；自动回归不访问真实 Qwen。

## 开始与停止门槛

1. **当前可做：** 仅需求、架构、计划、测试规格及关联说明文档编辑和文档检查。CR-WP01须下一次授权；业务代码、依赖、部署配置、迁移、数据/副本处置和实际回归不随本轮启动。
2. **模型计费门槛：** S3-11 每批先给出目的、输入数据、调用/重试量、费用估算、失败收费风险、外发字段与硬预算；产品负责人明确批准该批后才能调用。已有 Key 不代表批准。
3. **真实素材外发门槛：** 受控媒体访问 URL 的公网边界、撤销/过期和访问日志通过验证，产品负责人批准真实素材范围。先用非敏感或官方公开样本；不直接转发用户原始 URL。
4. **发布门槛：** 关键 AC、删除和跨用户隔离测试通过，管理员账户安全交付；P90、质量和容量若未达标，报告实际限制，不以架构批准替代证据。
5. **Git：** 本轮只在本地 `implementation` 分支准备 Step 3 内容。未经新的明确授权，不提交或推送后续实现和计划；当前远端 `implementation` 分支为旧基点，未来只采用快进更新，不覆盖历史。
