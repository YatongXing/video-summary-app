## 工作目标与边界

以 [ARCHITECTURE.md](ARCHITECTURE.md) 的已批准 MVP 基线实现可本地运行的网站。先用模型替身完成应用闭环和自动化回归，再通过单独批准的计费批次接入真实 Qwen。开发期间不上传真实用户视频或评测素材，不公开本地对象存储，不把 `.env`、密钥、带凭据 URL 或视频内容写入 Git/日志。所有任务的完成定义以可审查代码、对应验收项和必要测试证据为准。

## Agent 派发与交接规则

默认Main/Coding/Testing：Main维护计划/契约/文档与文件所有权、审阅/指派修复，不承担常规编码/测试；Coding只获准源码/迁移/必要自检；Testing提前从需求/AC独立设计并执行关键测试与复测，不以编码自检替代。共享文件由Main统一改，多Agent不得并写同文件。

WP03认证授权/隔离、WP04删除/并发、WP07正式切换/恢复/部署定向临时只读安全复核，不固定第四角色；其他重大风险Main提出专项。每派发九项：包/子任务ID、输入版本、模块/路径、冻结契约、必须/禁止、AC/T、交付证据、依赖交接。Agent完成不代表负责人验收，每包完成停等审核。

测试 Sub-agent 已独立核对 AC/E2E/ADR，建议把验证分为以下六包；各包在对应编码工作完成后提供执行证据，主 Agent 再审核：

| 测试包 | 对应实现与验收 | 独立验证重点 |
| --- | --- | --- |
| T1 身份与内容权限 | CR-002、新版 WP06、WP07-A | USER/ADMIN 本人内容及跨用户拒绝，旧 API 退役，元数据白名单、Task ID 搜索及视频续流门禁。 |
| T2 媒体与 URL | S3-04；AC-03/21 | 真实媒体属性、无音轨/损坏、HTTPS 直达、回环/内网与重定向、超限和 URL 凭据；使用本地受控媒体服务。 |
| T3 调度、额度、重试和取消 | S3-05/06；AC-04～10 | 假时钟覆盖 6 小时恢复、滚动 5 分钟、20 次上限及冷却；双 Worker、旧租约、重复扣退、ADR-002 越过；高风险合并门槛。 |
| T4 输出契约 | S3-07/08；AC-13～15 | 假模型返回双语、空事件、乱序、无效 Schema 或敏感字段；无效结果不得下载。 |
| T5 删除与保留 | S3-09历史 + CR-WP04/06；ADR-003/005 | Worker竞争、退避/诊断、危险删除停止、事件起算90天、历史副本/获准恢复及授权同步终止。 |
| T6 界面与指标 | S3-08/10/11；AC-11/12/22 | 五状态、UTC、进度、成功不弹窗；自动检查 P90 采集口径，实际 20 分钟目标及 15 视频质量由后续验证。 |

这些测试使用假时钟、假模型、受控媒体服务、PostgreSQL 集成环境和 Worker 故障注入；自动回归不访问真实 Qwen。

## 开始与停止门槛

1. **部署审批：** 目前有 WP07-A 隔离验证证据。候选镜像准备和正式创建、发布、开门按[执行清单](CR-WP07A_FORMAL_RUNBOOK.md)分别控制。文档整合在验收点结束。
2. **模型计费门槛：** S3-11 每批先给出目的、输入数据、调用/重试量、费用估算、失败收费风险、外发字段与硬预算；产品负责人明确批准该批后才能调用。已有 Key 不代表批准。
3. **真实素材外发门槛：** 受控媒体访问 URL 的公网边界、撤销/过期和访问日志通过验证，产品负责人批准真实素材范围。先用非敏感或官方公开样本；不直接转发用户原始 URL。
4. **发布门槛：** 关键 AC、删除和跨用户隔离测试通过，管理员账户安全交付；P90、质量和容量若未达标，报告实际限制，不以架构批准替代证据。
5. **Git：** 依 [Git 策略](GIT_STRATEGY.md)和具体授权处理工作区。文档整合只读检查差异，提交和推送另行授权。
