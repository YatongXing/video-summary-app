# 用户故事 — Video Summary App

**关联：** [PRD](PRD.md) · [范围](SCOPE.md) · [验收标准](AC.md)  
**状态**：按已验收的 [CR-002](CR-002.md) 和继续有效的产品规则整理。

| ID | 用户故事 | 优先级 |
| --- | --- | --- |
| US-01 | 作为中国地区个人用户，我希望用邮箱和密码注册/登录，每次新登录重新输入密码，并默认获得普通用户权限。 | 必须 |
| US-02 | 作为普通用户，我希望通过本地文件或可合法获取的视频 URL 导入符合 MP4/MOV、2 GB、2 小时及 H.264/AVC、AAC/MP3 限制的视频，并收到实际媒体校验错误的说明。 | 必须 |
| US-03 | 作为普通用户，我希望提交前确认视频授权，且只访问自己的任务和结果。 | 必须 |
| US-04 | 作为普通用户，我希望看到当前处理机会和下次自然恢复倒计时，并知道排队/实际开始时的额度变化。 | 必须 |
| US-05 | 作为普通用户，我希望任务校验通过后按已确认顺序排队，只有因同用户活动任务受阻时才允许其他用户可运行任务越过；我能看到五种明确状态及处理进度。 | 必须 |
| US-06 | 作为用户，我希望得到结合画面、音频及时间戳的中文或英文摘要，并导出可验证的 JSON。 | 必须 |
| US-07 | 作为用户，我希望失败时看到原因、退款结果和重试资格，并由统一的重试冷却/累计上限保护任务。 | 必须 |
| US-08 | 作为用户，我希望取消排队或处理中任务后，任务进入终态且不再重试或生成结果。 | 必须 |
| US-09 | 作为任务所有者，我希望删除后任务立即移出列表并禁止内容读取，关联内容/评测资料后台清理完成后内部才标成功，界面不虚报完成且无删除历史页面。 | 必须 |
| US-10 | 作为管理员，我希望在个人任务入口查看自己的摘要、双语 JSON 与视频。其他用户内容始终受保护。 | 必须 |
| US-11 | 作为部署者，我希望手动创建管理员账户，且普通注册流程无法授予管理员权限。 | 必须 |
| US-12 | 作为评测负责人，我希望通过本地应用界面手动运行 15 个授权视频并用单人标注建立初始质量基线，报告指标分母、缺失项和局限。 | 必须 |
| US-13 | 作为普通用户，我希望取消尚未开始或正在处理的任务，并明确知道取消后的终态及额度处理。 | 必须 |
| US-17 | 作为部署者，我希望在没有人工清理产品页面时仍可发现持续故障、受控诊断/再推进，并让归属不明的危险删除停止。 | 必须 |
| US-18 | 作为部署者，我希望避免新增内容备份，先核实现有副本再申请清理，并明确数据丢失不可恢复风险。 | 必须 |

| US-19 | 作为管理员，我希望通过 Task ID 在只含白名单元数据的工作台定位任务，清空输入时回到默认列表。 | 必须 |
| US-20 | 作为任务所有者，我希望在任务名称下复制真实任务编号，展开结果时只看到一次编号。 | 必须 |
| US-21 | 作为用户，我希望在已配置反馈邮箱时从页脚打开邮件客户端。 | 必须 |

历史 US-14～16 对应已退役的排障请求、待处理队列和撤权交互。原场景见 [CR-001 测试规格](archive/cr/CR-001_TEST_PLAN.md)。
