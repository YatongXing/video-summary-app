# 用户故事 — 视频多模态总结应用

**关联：** [PRD](PRD.md) · [范围](SCOPE.md) · [验收标准](AC.md)  
**状态：** Step 1 需求基线

| ID | 用户故事 | 优先级 |
| --- | --- | --- |
| US-01 | 作为中国地区的已登录个人用户，我希望确认我拥有处理授权后上传不超过 3 小时的视频。 | 必须 |
| US-02 | 作为用户，我希望看到格式、大小、时长或授权确认缺失的明确提示。 | 必须 |
| US-03 | 作为普通用户，我希望知道剩余额度和下一次恢复时间。 | 必须 |
| US-04 | 作为用户，我希望看到排队、进度和预计/目标时长，并在私有历史中找回任务。 | 必须 |
| US-05 | 作为用户，我希望得到结合语音、画面和时间线的总结，而不只是字幕摘要。 | 必须 |
| US-06 | 作为用户，我希望查看总览、要点、章节和关键时刻，并通过时间戳回看证据。 | 必须 |
| US-07 | 作为用户，我希望导出中文或英文 JSON。 | 必须 |
| US-08 | 作为用户，我希望看到失败原因并在允许时重试，同时了解冷却或重试上限。 | 必须 |
| US-09 | 作为用户，我希望删除自己的视频、结果和历史记录；未删除项目在 30 天内可查看。 | 必须 |
| US-10 | 作为管理员，我希望按用户查看处理日志并拥有无限处理额度。 | 必须 |

## 后续（非 MVP）

- 通过 YouTube 或 Bilibili 的合法授权方式导入公开视频。
- 公司账户、共享和协作能力。
- 其他语言与混合语言视频。
