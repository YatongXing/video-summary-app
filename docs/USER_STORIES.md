# 用户故事 — Video Summary App

**关联：** [PRD](PRD.md) · [范围](SCOPE.md) · [验收标准](AC.md)  
**状态：** Step 1 需求基线更新稿

| ID | 用户故事 | 优先级 |
| --- | --- | --- |
| US-01 | 作为中国地区个人用户，我希望用邮箱和密码注册/登录，并默认获得普通用户权限。 | 必须 |
| US-02 | 作为普通用户，我希望上传符合 MP4/MOV/WebM、4 GB、3 小时及 H.264/AVC、AAC/MP3 限制的本地视频，并收到实际媒体校验错误的说明。 | 必须 |
| US-03 | 作为普通用户，我希望提交前确认视频授权，且只访问自己的任务和结果。 | 必须 |
| US-04 | 作为普通用户，我希望看到当前处理机会和下次自然恢复倒计时，并知道排队/实际开始时的额度变化。 | 必须 |
| US-05 | 作为普通用户，我希望任务校验通过后按 FIFO 排队、看到五种明确状态及处理进度，不被承诺精确 ETA。 | 必须 |
| US-06 | 作为用户，我希望得到结合画面、音频及时间戳的中文或英文摘要，并导出可验证的 JSON。 | 必须 |
| US-07 | 作为用户，我希望失败时看到原因、退款结果和重试资格，并由统一的重试冷却/累计上限保护任务。 | 必须 |
| US-08 | 作为用户，我希望取消排队或处理中任务后，任务进入终态且不再重试或生成结果。 | 必须 |
| US-09 | 作为用户，我希望删除后立即无法访问任务，并在在线数据完成清理后才收到删除成功确认。 | 必须 |
| US-10 | 作为管理员，我希望按用户查看任务元数据，但只有在获得指定任务授权后才能查看视频或摘要内容。 | 必须 |
| US-11 | 作为部署者，我希望手动创建管理员账户，且普通注册流程无法授予管理员权限。 | 必须 |
| US-12 | 作为评测负责人，我希望依据 15 个授权视频和单人标注建立初始质量基线，并报告指标分母、缺失项和局限。 | 必须 |
| US-13 | 作为普通用户，我希望取消尚未开始或正在处理的任务，并明确知道取消后的终态及额度处理。 | 必须 |
