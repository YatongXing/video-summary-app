# 视频多模态总结应用 — 产品需求文档（PRD）

**状态：** Step 1 需求基线（待产品负责人确认）  
**版本：** 0.2 · **日期：** 2026-10-26 · **阶段：** 仅需求定义，尚未开始架构或产品实现。

## 产品与边界

面向中国地区的个人用户。用户登录后上传视频，系统异步理解全片语音、画面、文字、图表、动作与时间脉络，返回可核查的带时间戳总结；不是只压缩字幕。最终产品形态是网站。

MVP 只接受本地视频上传，不提供 URL 导入。每个任务、视频和结果均为私有；没有匿名试用、公司账户、团队共享或协作。提交时用户确认拥有上传和处理视频所需权利与授权。

## 已确认决策

| 决策 | 内容 |
| --- | --- |
| 用户与账户 | 中国地区个人用户；普通用户使用邮箱 + 密码注册和登录。管理员账户由部署者手动创建，不开放管理员自助注册；管理员可按用户审阅处理日志。 |
| 输入 | 单视频最长 3 小时（180 分钟）；文件格式和大小尚待确认。 |
| 保留与删除 | 视频、结果与处理历史默认保留 30 天；用户可主动删除。管理员日志的保留/物理清除规则待定。 |
| 处理额度 | 普通用户最多 3 个额度；每消耗 1 个后每 6 小时恢复 1 个，最多 3 个。管理员无限。 |
| 队列 | 每位用户唯一 ID。任务按进入队列时间排序；同一时间按用户 ID、再按任务创建顺序稳定排序。全局和单用户并发上限待定。 |
| 进度与性能 | 显示状态、进度及预计/目标完成时长。60 分钟合格视频端到端 P90 ≤20 分钟。成功时只更新界面，不弹窗。 |
| 失败与重试 | 显示可理解原因。5 分钟内第 5 次及以后重试触发更长等待；后续突发的等待逐步增加。每视频项目累计用户重试达 20 次后禁止再次重试。具体冷却参数待定。 |
| 语言与导出 | 仅中文/英文语音输入；可导出结构化中文 JSON 与英文 JSON；其他语言不在 MVP。 |
| 质量样本 | 至少 30 个经授权视频，管理员在本地下载并维护。 |
| URL 路线 | URL 导入不在 MVP。未来仅评估 YouTube、Bilibili 的合法、已授权路径；明确排除私密、登录态、付费、DRM 内容及规避平台限制的方式。 |

## 核心体验与功能

主路径：登录 → 确认权利声明 → 上传 → 查看排队/处理进度 → 查看结果或失败原因 → 导出 JSON、删除或在 30 天内回看历史。

成功结果包括一句话总览、3–7 条要点、覆盖完整时间线的章节、3–10 个关键时刻、可跳转时间戳、必要的视觉/音频证据提示和局限说明。不得把未覆盖、无声、不可解码或低质量片段表述成已完整理解。

| ID | 需求 | 优先级 |
| --- | --- | --- |
| FR-01 | 普通用户通过邮箱 + 密码注册/登录；管理员账户仅由部署者手动创建，不提供管理员注册入口。登录后为私有访问、权利/授权确认和最长 180 分钟的本地视频上传。 | 必须 |
| FR-02 | 持久的私有任务/历史、状态、进度与预计时长。 | 必须 |
| FR-03 | 连续时间线的音频、视觉、OCR、场景和时间对齐分析。 | 必须 |
| FR-04 | 带时间戳的多模态总结、局限披露及中文/英文 JSON 导出。 | 必须 |
| FR-05 | 普通用户额度、确定性队列、失败原因、递增冷却和 20 次重试上限；管理员免额度。 | 必须 |
| FR-06 | 用户删除/30 天过期；管理员按用户查看处理日志。 | 必须 |

## 质量与明确排除

“完整观看”意为有效时间线连续分段，每段都有音频、视觉或两者的覆盖/失败状态。质量门槛见 [QUALITY_EVALUATION.md](QUALITY_EVALUATION.md)，端到端验收见 [E2E_TEST_PLAN.md](E2E_TEST_PLAN.md)：时间线覆盖率 ≥99%，章节覆盖率 ≥90%，关键事实支持率 ≥95%，关键视觉事件召回率 ≥85%，时间戳可用率 ≥90%。

MVP 排除 URL 导入、直播/实时总结、剪辑、字幕编辑、翻译配音、公司账户/协作，以及其他输入语言。

## 尚未决策（Step 1）

1. 支持的文件格式、最大文件大小和断点续传规则。
2. 全局/单用户并发上限、管理员队列优先级和额度扣减/返还时点。
3. 冷却时长、递增/重置公式；当前“20 次”暂按用户手动重试理解。
4. 删除、过期、备份和管理员日志的物理清除/保留时限及管理员访问审计。
5. 页面默认展示语言、JSON 字段翻译规范和中英混合语音的处理。
6. 评测集标注负责人、样本配额及质量门槛批准人。

这些事项确认后，下一阶段才可设计架构、Agent/Skill 合约、安全和可观测性；本阶段不做实现。
