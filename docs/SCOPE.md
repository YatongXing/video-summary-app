# 功能范围 — 视频多模态总结应用

## MVP 范围

- 中国地区个人用户注册、登录、私有任务访问；普通用户与管理员角色。
- 上传时确认拥有权利/授权；本地上传，单视频最长 180 分钟。
- 视频、结果和历史默认保留 30 天；用户删除；管理员按用户审阅处理日志。
- 普通用户 3 个处理额度，每 6 小时恢复 1 个（最大 3 个）；管理员无限。
- 使用进入时间、用户 ID、任务创建顺序作为队列稳定排序键；并发上限待定。
- 状态、进度、预计/目标时长、失败原因、重试、递增冷却与单项目 20 次累计重试上限。
- 中文/英文语音的连续时间线多模态分析；带时间戳总结和中文/英文 JSON 导出。
- 合格 60 分钟视频的端到端 P90 ≤20 分钟；成功仅更新界面、不弹窗。

## 排除

- MVP 中的任何 URL 导入。
- 私密、需登录、付费、DRM 内容，或规避平台规则、版权和访问控制的方式。
- 直播、实时总结、视频编辑、字幕编辑、配音、公司账户、团队协作和其他输入语言。
