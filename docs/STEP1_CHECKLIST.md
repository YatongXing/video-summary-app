# Step 1 决策清单 — Video Summary App

## 已确认（Confirmed）

- [x] MVP 面向中国个人用户；本地上传或 URL 导入；MP4/MOV/WebM，2 GB 上限，2 小时上限，视频 H.264/AVC；如含音轨则 AAC/MP3；两种输入均由服务端校验实际媒体信息、解码性；不凭名称/MIME/URL 后缀判断，不静默截断。用户确认处理授权；排除绕过访问限制/DRM/平台保护。
- [x] 必要预处理失败终止任务并说明原因；敏感内部细节不得呈现给用户。
- [x] 邮箱/密码普通用户注册登录，账户持久保存且可再次登录；MVP 不要求邮箱验证/审核，身份模块保留扩展空间；核心功能必须登录；新注册始终为普通角色，管理员部署者手动创建，禁止公开管理员注册；普通任务私有；密码安全哈希、不明文保存。实现完成后由部署者安全创建并交付管理员账户。
- [x] 每次新登录要求密码，MVP 无免密码自动登录；注册/登录实施可配置基本限速。用户撤销管理员对指定任务的内容授权后，后端拒绝后续访问并停止可中断传输；已下载到外部的副本无法由系统收回。
- [x] 管理员默认按用户查看任务元数据；访问指定原视频/摘要需要任务级明确授权及后端校验、审计。
- [x] 普通用户初始 3 次；余额低于 3 后每 6 小时恢复 1 次至 3；活动计时不因使用重置，满额停、再次低于 3 重开；服务端权威，UI 显示余额和倒计时；退款与自然恢复计时独立。
- [x] 实际开始才扣额；同任务重试不另扣；内部错误、外部模型服务超时/限流/不可用及未知错误退款；明确用户输入问题和取消不退款；每个符合条件的失败事件只退款一次且退款幂等、额度封顶 3；竞态有确定分类规则。
- [x] Worker 崩溃/重启不造成重复扣额，若任务因内部故障失败则按系统错误退款；模型超时后的第 4 次及更晚重试依旧不另扣处理机会。外部 Token 费用与用户处理机会分开记账。
- [x] 首次尝试不计重试；滚动 5 分钟前 4 次已接受、第 5 次触发冷却；累计 20 次已接受，第 21 次拒绝；自动/手动同规、重复请求幂等；拒绝不计数、不启动、不延长冷却；取消任务终态、新任务不继承计数。
- [x] 冷却阶梯 1/5/15/30 分钟、30 分钟封顶；同一任务级别不重置，前次到期后新触发才升级，新任务重新起步。
- [x] 排队按提交时间、用户 ID、任务 ID 排序；队首仅因所属普通用户已有活动任务而受阻时，允许其他用户最早可运行任务越过，同用户仍保序；普通用户最多 1 个活动任务；系统并发可配置；管理员不插队。MVP 预计同时上传者不超过 5 人；设计需可扩展到 10–30 人同时使用，但这些是规划负载，不是已验证容量。
- [x] 用户可见状态仅 Queued、Processing、Completed、Failed、Cancelled；`SUCCEEDED` 映射到 Completed；UTC 保存时间；日志包含时间、时长、最终状态、原因和重试记录。进度可见，不承诺 ETA；成功仅更新界面、不弹窗。
- [x] 取消的终态、配额与竞态规则；成功状态不被迟到取消覆盖；后台作业不得在取消后启动/重建结果。
- [x] 性能目标为 60 分钟成功任务实际处理 P90 ≤20 分钟，不含队列；失败另报。无固定可用率/成功率 SLO。
- [x] 中英文语音和摘要 JSON；PRD 定义 Schema 1.0、字段限制和校验；无关键事件时允许空数组；无效 JSON 不可下载，失败按系统错误退款。
- [x] 任务创建时起 30 天保留、覆盖所有状态；普通任务日志保留 30 天。主动删除即限制访问并启动任务衍生数据与可关联评测资料清理；自动重试超过 3 次（不含首次尝试）或启动后超过 30 分钟未完成即通知管理员，支持经审计的管理员手动再次清理；完成前不得报成功。备份删除不晚于删除后 30 天；删除审计留 90 天。
- [x] 初始质量集 15 个授权视频、项目负责人本地下载并通过本地应用界面手动运行、建议五类各约 3 个；每视频一位标注者，无独立复核；保留输出/标注/评测/失败案例且受源任务删除规则约束。匹配事件报告时间戳误差中位数、P90及 ±5 秒（含边界）容差内比例；这是初始评测容差，不是整体质量门槛；正式质量阈值待基线后决定。

## 建议默认与待确认

- [ ] 首轮 URL 建议只接受合法 HTTPS 直达媒体文件；YouTube/Bilibili 播放页面集成另作权利和技术评估。最终支持范围由产品负责人确认。
- [ ] 模型可读取本地媒体的安全传输路径和任何公网入口须另行确认；不得仅因用户提供 URL 就直接转发其原始地址给模型。

## 需技术验证（Requires technical validation）

- [ ] 已批准容器与 codec 的组合在媒体预处理路径中的真实兼容性。验证不得静默扩展 MP4/MOV/WebM、H.264/AVC、AAC/MP3 白名单。
- [ ] Qwen3.8-Omni-Flash 的完整 2 小时/2 GB 媒体输入路径、北京区域/数据留存/训练用途/条款/费用及 P90 可行性；付费调用和真实素材外发分别须获授权。
- [ ] 北京 Windows 11 家庭局域网部署下，5 人同时上传及 10–30 人使用的容量和最小防饥饿机制；本地备份介质可恢复性。

## Step 1 状态与后续

配额、重试、保留、JSON Schema、2 小时/2 GB、双输入、条件越过、评测样本数量和初始 ±5 秒时间戳容差已确定。正式质量阈值、SLO 和修复次数延期。白名单与模型输入兼容性、部署及容量仍须验证。

本清单记录需求状态，不表示架构已最终批准或功能已实现；正式质量门槛在基线评测后另行确定。
