# Step 1 决策清单 — Video Summary App

## 已确认（Confirmed）

- [x] MVP 面向中国个人用户；仅本地上传；MP4/MOV/WebM，4 GB 上限，3 小时上限，视频 H.264/AVC；如含音轨则 AAC/MP3；服务端校验实际媒体信息、解码性；不凭名称/MIME 判断。用户上传前确认处理授权；YouTube/Bilibili 不属于 MVP，未来仅限合法授权路径，排除绕过访问限制/DRM/平台保护。
- [x] 必要预处理失败终止任务并说明原因；敏感内部细节不得呈现给用户。
- [x] 邮箱/密码普通用户注册登录，核心功能必须登录；新注册始终为普通角色，管理员部署者手动创建，禁止公开管理员注册；普通任务私有；密码安全哈希、不明文保存。
- [x] 管理员默认按用户查看任务元数据；访问指定原视频/摘要需要任务级明确授权及后端校验、审计。
- [x] 普通用户初始 3 次；余额低于 3 后每 6 小时恢复 1 次至 3；活动计时不因使用重置，满额停、再次低于 3 重开；服务端权威，UI 显示余额和倒计时；退款与自然恢复计时独立。
- [x] 实际开始才扣额；同任务重试不另扣；内部错误、外部模型服务超时/限流/不可用及未知错误退款；明确用户输入问题和取消不退款；每个符合条件的失败事件只退款一次且退款幂等、额度封顶 3；竞态有确定分类规则。
- [x] 首次尝试不计重试；滚动 5 分钟前 4 次已接受、第 5 次触发冷却；累计 20 次已接受，第 21 次拒绝；自动/手动同规、重复请求幂等；拒绝不计数、不启动、不延长冷却；取消任务终态、新任务不继承计数。
- [x] 冷却阶梯 1/5/15/30 分钟、30 分钟封顶；同一任务级别不重置，前次到期后新触发才升级，新任务重新起步。
- [x] 排队 FIFO，平手按用户 ID、任务 ID；普通用户最多 1 个活动任务；系统并发可配置；管理员不插队。
- [x] 用户可见状态仅 Queued、Processing、Completed、Failed、Cancelled；`SUCCEEDED` 映射到 Completed；UTC 保存时间；日志包含时间、时长、最终状态、原因和重试记录。进度可见，不承诺 ETA；成功仅更新界面、不弹窗。
- [x] 取消的终态、配额与竞态规则；成功状态不被迟到取消覆盖；后台作业不得在取消后启动/重建结果。
- [x] 性能目标为 60 分钟成功任务实际处理 P90 ≤20 分钟，不含队列；失败另报。无固定可用率/成功率 SLO。
- [x] 中英文语音和摘要 JSON；PRD 定义 Schema 1.0、字段限制和校验；无关键事件时允许空数组；无效 JSON 不可下载，失败按系统错误退款。
- [x] 任务创建时起 30 天保留、覆盖所有状态；主动删除即限制访问并启动全量任务衍生数据清理；失败自动重试、超配置限制告警并转人工处理；备份删除不晚于删除后 30 天；删除审计留 90 天。
- [x] 初始质量集 15 个授权视频、管理员本地下载、建议五类各约 3 个；每视频一位标注者，无独立复核；保留输出/标注/评测/失败案例。匹配事件报告时间戳误差中位数、P90及 ±5 秒（含边界）容差内比例；这是初始评测容差，不是整体质量门槛；正式质量阈值待基线后决定。
