# Step 1 完成清单 — 需求定义与规划准备

## 已确认

- [x] 中国地区个人用户；网站形态。
- [x] 普通用户使用邮箱 + 密码注册/登录；管理员由部署者手动创建，不开放管理员注册。私有任务，无试用/公司账户；管理员可按用户审阅处理日志。
- [x] 视频、结果和处理历史默认 30 天，用户可删除。
- [x] 权利/授权确认、3 小时视频上限。
- [x] 普通用户 3 个额度、每 6 小时恢复 1 个；管理员无限；用户唯一 ID 和基于时间/ID 的稳定队列排序。
- [x] 60 分钟 P90 ≤20 分钟、进度/预计时长、成功无弹窗。
- [x] 失败原因与重试；5 分钟超过 4 次触发递增等待；单视频项目累计最多 20 次重试。
- [x] 中文/英文语音输入、中英文 JSON 导出；其他语言不在 MVP。
- [x] 至少 30 个经授权、管理员本地下载的评测视频。
- [x] URL 导入不在 MVP；未来只探索 YouTube/Bilibili 合法授权路径，排除私密/登录/付费/DRM 和规避限制方式。
