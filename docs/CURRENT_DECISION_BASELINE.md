## 3. 保留的旧版产品规则

普通用户邮箱+密码注册登录；注册只能取得普通角色；管理员由部署者手动创建；登录后才能使用核心功能，任务私有。普通用户初始 3 次机会、低于 3 时每 6 小时恢复 1 次；真正开始处理时扣额，同任务重试不额外扣额。内部错误、外部模型超时/限流/不可用及未知错误退款；已扣额的用户输入问题或主动取消不退款；退款幂等且余额封顶 3。首次处理不算重试；滚动 5 分钟第 5 次已接受重试触发冷却；任务累计最多 20 次已接受重试，冷却依次 1/5/15/30 分钟并封顶。以上细节以远端 [PRD §4](PRD.md) 和 [AC-04～09](AC.md) 为准。

输出为中文/英文摘要及固定 JSON 1.0 结构；用户删除立即限制访问并启动清理，未实际清理完成不能报成功。管理员默认仅看元数据，查看某任务原视频/摘要须该任务用户明确授权并留审计。URL 导入现属 MVP，具体范围见 CD-09。
