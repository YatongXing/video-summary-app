## 2. 两类数据库权限（R-05）

运行角色供API/Worker受限业务DML，非owner/NOSUPERUSER/NOCREATEDB/NOCREATEROLE、无DDL/不继承维护角色，正式切换后禁止task_consents的INSERT/UPDATE及purpose/access_scope/revoked_at等授权判断读取；仅为任务清退保留DELETE和筛选所需task_id（按归属筛选时加user_id）列SELECT，不给旧授权查询SELECT全表。核查PUBLIC/default grants、SET ROLE/函数search_path旁路；应用内角色与用户隔离仍靠服务端。

受控维护角色兼schema owner、迁移及受支持维护CLI，不必superuser。凭据只在一次性维护环境，普通API不持有/不提供代调用。默认不另建owner/migrator/ops三套身份；初始设施管理员仅一次性配置通道，不作为服务身份。维护owner属受信部署者，不能声称数据库防其直接SQL，也不能把容器UID当真实逐人认证。

当前Compose共用PG_USER可能为初始化高权限账号，正式切换先证明新维护通道可重连，再配置新运行身份、停旧连接/旧运行凭据失权，避免锁死唯一维护通道。旧binary不读新门禁，必须实际停止并撤其可用权限，不能只改版本标记。

兼容说明：现有cleanup._purge_bodies_and_logs按task_id删除task_consents，旧外键会阻塞task清退；上述最小DELETE/定位列读取既保留实际删除，也不能让旧目的授权API读取有效授权或重新创建。WP02角色反例须同时证明安全清退可行和旧授权SELECT/INSERT/UPDATE拒绝；真实赋权仍仅WP07。

WP02专用可销毁PG17实例、*_test库/UUID schema及合成运行/维护角色验证；角色是集群级资源，schema不足隔离。真实角色/连接/秘密处理只WP07专项授权，不读真实.env来测试。

## 3. 显式维护门禁与独立删除控制

保留现有独立journal、identity、fsync原子意图/启动重放，不与业务内容卷同回滚。控制缺失/损坏/归属不匹配不得重建空日志后开放。

显式maintenance.required位于独立控制位置，受控维护通道原子持久化/清除；普通API不提供操作入口/不持维护凭据。API/Worker启动、就绪及运行读写/授权/视频续传均检查，标志存在或控制失信则不开放业务。普通重启正常核验/重放，不无故撤销有效会话/授权。

不建授权auth_epoch/security_epoch/min_runtime专用表；用既有schema_migrations校验支持结构。该最小门禁不自动识别任意同identity旧DB/整机快照回滚；只支持明确隔离的维护恢复，已获风险边界认可。旧服务不受新标志自动约束，先停旧服务/网络/连接。

## 4. WP07正式切换

1. WP06验收后，取得实例/时段/精确迁移/旧授权终止范围的M3专项授权；固定代码/SQL/checksum及维护计划、无需含内容备份。
2. 关闭入口，持久维护门禁；排空旧API、Worker/FFmpeg后代、清理I/O和连接，保留当前独立控制；无停止证据不启动新清理。
3. 维护角色执行已审结构资产，验证两类角色/凭据隔离/维护可重连；旧运行身份失权。源任务/结果/资产与配额仅无内容计数/归属对账，不dump真实内容。
4. 独立受控M3事务终止全部旧目的授权，演练残留新授权亦终止，写最小切换事件；不自动生成请求。事务失败不开放。
5. 隔离启动新服务，重放删除意图；核验旧API410/旧凭据失权、owner/三范围/UUID/版本、实际最低health与部署者发现渠道。合成检查需专项资源授权，不删真实源任务。
6. 检查通过后部署者清维护标志再开放，通知用户重新授权。任何失败保留维护/诊断，不恢复无限期purpose。

## 5. 安全回退与离线恢复

首选向前修复；只回经验证兼容当前结构/新权限语义的镜像，不down-migrate或回旧purpose服务；首次新协议无兼容旧镜像则保持维护。迁移失败安全诊断/重放，不以新内容快照做回退保障。

任何历史恢复另行授权，先关闭入口/停旧服务/连接及在途I/O、持久维护标志；保留当前独立删除控制，核快照时间/identity/归属，>=90天、时间不可信或适用删除意图证据不足拒绝开放。恢复后强制重放已确认删除，重新核验对象/目录/SQL，不相信快照完成状态。

开放前事务终止恢复库全部sessions、旧purpose和新support请求，提交成功才继续；旧UUID不能恢复授权，用户重新登录/授权。核DB权限及应用管理员/停用账户当前可信状态，无法确认保持相关访问关闭/维护，不自动沿用旧管理员。通过结构/删除/授权/账户/health核验后由部署者清门禁。中断或终止授权失败时标志保留，所有业务读写/续传拒绝。

正常运行support_version单调，离线恢复旧库不保证跨快照单调；依靠排空旧请求、旧会话/CSRF/授权失效、重新登录清前端待提交操作阻止旧mutation自动继续。若未来要求任意回滚自动检测或授权连续性，须另审外部单调控制，不现在构建企业级灾备。

无新内容备份；Git/配置/结构资料只能重部署软件，视频/摘要/账户元数据可能永久丢失，重传重算可能计费且不一致。下载/供应商/介质历史字节限制保留。
