## 4. 必要的真实并发与恢复证明

- WP04真实Linux Docker本地共享卷/双容器/实际FFmpeg/ffprobe，父SIGKILL子仍写、FD继承、稳定inode/替换、SH/EX和DB锁顺序；未证停止不清目录。不以线程退出、lease或HTTP404单独当物理oracle。
- 旧清理I/O在claim概念取消后仍不能重叠，全局物理锁未释放不接管；DB断连后真实I/O未返回、重启/崩溃需重验目标。分别看进程、文件、SQL、S3。
- N>=2真实跨用户同时生产，普通用户最多1、FIFO/平手/唯一越过，删A不伤B；原配额/退款/重试/取消全测，不新增全局单任务限制。
- WP07恢复前maintenance标志后中断、授权终止提交失败、标志存在/控制失信时所有读写/续传/Worker拒绝；强制重放，恢复库全部sessions/旧purpose/新support失效；应用管理员/停用状态不明保持相关关闭；>=90天/证据不足拒开放。正常重启不撤有效授权。
- WP04实现最低health/持久信号，WP06故障闭环，WP07开放前部署者实际发现证据；S3-12只完善。R-03失败停方案另审替代，R-04字段WP04前冻结后测试，R-05实际权限/恢复在WP07，不提前要求WP01运行。

## 6. 新基线人工验收（实施后才可执行）

1. 两角色无删除历史/人工页，正常任务删除确认仍在；管理员自己的任务无排障申请、直接双语摘要/JSON/视频。
2. 普通用户三scope生成UUID/期限/撤销；summary不视频、video不JSON，编号查找和列表只定位授权任务。
3. 列表自动接收、创建时间/ID排序、复制编号；替换新ID/24h/重排，旧ID/撤销/过期/删请求/删task失效。
4. 双击/丢响应/409恢复只查询，不自动重新授权；旧浏览器响应不覆盖新版本，登出切账号清内存。
5. 合成删除接受后拒访问，后台实际清理才成功；故障、三入口及发现链只在获准隔离资源检查，原内容和他人任务不误伤。
6. WP07专项旧授权终止/维护门禁/恢复/角色及最低发现核验；边界说明下载/供应商/历史字节和不可恢复风险。

结果记录版本/实例/操作者、通过/失败/未执行，不附真实秘密/私密内容。本节为人工验收规格，实际执行状态见各包报告；WP06人工清单仍待产品负责人操作。
