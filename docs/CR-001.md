## 2. 已批准决策登记

| ID | 已批准内容 |
| --- | --- |
| D-01 | 用户或管理员删除自己拥有的任务时，清理应用控制的原视频、派生文件、摘要及内容型记录；只保留最小无内容审计，不主动创建应用级视频内容备份。 |
| D-02 | 排障访问码由系统自动生成，不要求普通用户自行设置密码。 |
| D-03 | 一个访问码只对应一条任务，不跨任务共享。 |
| D-04 | 从服务端记录的成功创建时间起有效 24 小时。 |
| D-05 | 管理员删除请求时移除请求并立即撤销关联授权；不删除用户原任务。 |
| D-06 | 每任务同时最多一个有效码；重新生成立即使旧码失效，新码重新计算 24 小时。 |
| D-07 | 管理员有效待处理列表直接显示访问码，访问码用于定位而不替代管理员认证和任务级授权。 |
| D-08 | 取消内容备份对 S3-12 的影响须单独分析和审批，不自动实施。S3-12 目标范围现已按 CR-D09～16 更新，执行仍需后续授权。 |
| CR-D09 | 不主动创建原视频、派生媒体和摘要的应用级备份；后续部署避免新建含这些内容的数据库整库备份或系统快照。可保留无用户内容的代码、配置模板、结构定义和部署说明。历史备份、自动快照和基础设施副本先核实，不能擅自删除；S3-12 明确不可恢复风险及范围。 |
| CR-D10 | 历史副本先清点、隔离、核实，再经批准清理；处置完成前保留必要的受控清理能力。 |
| CR-D11 | 移除管理员人工清理页面；临时故障带退避和频率上限重试，持续故障留部署者可发现的错误和故障信号，危险或归属不明删除停止自动执行；提供受控且可审计的部署者诊断/再推进，不虚报成功。具体参数和命令先提出审核，不能直接实施。 |
| CR-D12 | 删除审计从相应审计事件发生时间起保留 90 天，仅必要无内容字段，到期清理。未完成作业可保留必要执行控制直到完成或经授权解决，不视为成功。 |
| CR-D13 | 撤销、过期、替换或任务删除使请求立即退出有效待处理列表；新码对应新请求，按新创建时间重新排队；无历史排障请求管理页面。 |
| CR-D14 | 正式切换时统一终止旧目的授权，不自动转码；用户重新授权，旧 API 不能绕过 24 小时规则。 |
| CR-D15 | 摘要范围含中英文摘要及对应 JSON，不含视频；仅视频不含摘要及 JSON；两者授权同时包含。 |
| CR-D16 | 完成验收覆盖应用实际控制的数据库内容、私有对象、派生文件、工作目录和相关内容资产；说明基础设施历史字节、用户下载和模型服务商副本限制，不承诺物理介质安全擦除。 |

## 3. 继续有效与被替代的旧规则

| 旧基线 | CR-001 后的效力 |
| --- | --- |
| ADR-001 模块化应用、持久队列、独立 Worker；ADR-002 视频调度 | 继续有效，排障列表排序不改变视频处理调度。 |
| ADR-003 的源任务/评测反向关联、删除栅栏、幂等清理、防迟到重建 | 继续有效，去标识化不免除关联删除。 |
| 任务及普通任务日志自任务创建起 30 天 | 继续有效，覆盖全部状态；到期安全停止并清理，且终止排障授权。 |
| 删除审计 90 天 | 继续有效并明确按各审计事件时间计算；不以任务创建或最近一次重试重置。 |
| ADR-003/004 的管理员清理界面和一键再推进 | 由 CR-D11 替代为部署者可发现的后台信号与受控诊断/再推进；参数及命令待审核。 |
| 内容备份和常规内容恢复规划 | 由 CR-D09/10 替代；不再新增内容备份，历史副本保留治理能力。 |
| 删除后备份最迟 30 天清除、恢复防复活 | 历史副本过渡期仍履行原清除期限，不擅自延期；需事先批准具体清理。任何获准恢复继续防复活、撤销旧会话及授权。不能为凑期限直接删除未知副本。 |
| 目的字段匹配、允许多条无期限目的授权 | 由 D-02～06、CR-D14 替代为系统码、单任务、唯一当前授权、24 小时和切换终止。 |
| 管理员内容访问一律需要用户授权的笼统表述 | 对自己任务按所有权直接访问；其他用户任务仍须当前任务级授权。 |
| 删除回执/备份核验产品页面 | 移除；内部清理状态与最小审计继续存在，接受删除不等于已完成。 |

若历史副本无法在原期限内核实并经批准处置，应记录未达要求、隔离恢复路径并提交处理方案；禁止伪造完成或自行延长期限。

## 4. 尚需实施评审的技术细节

产品决策均已确认，不再重复提问。以下为 CR-WP01 的实施方案输出，不是产品决策冲突或本轮实施授权：

- 请求/授权采用同一权威记录的具体表结构、状态、唯一约束、外键和索引；字段清退顺序。
- 随机码位数和编码、查找摘要与认证加密、密钥注入/轮换、失败时的拒绝策略。
- 原子生成/替换/撤销/删除、统一内容鉴权、幂等键、服务端时间及锁顺序。
- 无效码限速参数、日志脱敏、浏览器内存生命周期。
- 清理退避、频率上限、持续故障阈值、发现渠道、部署者命令与权限/审计。
- 排障终止事件的无内容审计字段和期限；CR-D12 已确定的是删除审计，不把其余审计期限未经评审一律改为 90 天。
- 历史副本清点和隔离方法、退役完成证据、获准恢复与升级回退边界。

建议随机码和加密等细节仅作为候选，不因“原则认可技术方向”标成具体实现已批准。遇到实质性技术冲突，只停止受影响部分并单独报告。
