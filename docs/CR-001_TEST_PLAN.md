## 2. CR验收追踪

| ID | 场景 | 验证方法/证据要求 |
| --- | --- | --- |
| CR-AC-01 | 用户删除已完成任务 | 合成已完成双语任务，经HTTP删除；原片对象、SQL结果/导出、工作区及关联记录逐项查验，202与完成分离。 |
| CR-AC-02 | 删除正在处理任务 | 在预处理、模型替身返回、发布前和提交时删除；暂停旧Worker后恢复，检查进程/目录和旧代次拒绝。 |
| CR-AC-03 | 存储删除失败 | 注入删除抛错、HEAD仍存在、超时/权限错误；可控时间验证退避和频率上限、重启后继续、完成证据。 |
| CR-AC-04 | 普通用户及管理员界面 | 真实React交互和路由/API检查，普通/管理员均无删除历史能力；内部作业仍可诊断。 |
| CR-AC-05 | 管理员工作台 | 检查旧人工/备份界面和产品API退役，改以批准部署者诊断入口测试。 |
| CR-AC-06 | 管理员自己的任务 | 管理员上传合成任务，两界面所有者路径读zh/en、JSON和视频Range，无码；自授权API拒绝。 |
| CR-AC-07 | 管理员直接读普通用户内容 | 管理员直接请求用户所有者URL、改task_id/请求ID、无授权内容路径均拒绝。 |
| CR-AC-08 | 普通用户创建授权 | 检查服务端绑定/时间/范围和随机来源，强制随机碰撞验证重生与唯一约束；无需密码/目的。 |
| CR-AC-09 | 重新生成码 | 先授权后替换，用旧码/旧请求ID分别解析和读取，列表仅新请求，新时间重新排队。 |
| CR-AC-10 | 多任务授权 | 同用户两任务及不同用户任务分别生成，交叉码/任务组合失败。 |
| CR-AC-11 | 管理员待处理列表 | 真实后端列表投影及前端复制交互，只含普通用户有效请求，无正文/额外敏感字段。 |
| CR-AC-12 | 输入有效码 | 解析接口返回单条任务；列表与手动入口逐项复用同一权限矩阵。 |
| CR-AC-13 | 未授权内容类型 | summary/video/both × zh/en摘要/JSON/视频及直接URL/Range的允许拒绝矩阵。 |
| CR-AC-14 | 到期 | 可控服务端时钟覆盖到期前、恰好24h、之后；禁用过期整理和重启仍拒绝；不存在管理员延期入口。 |
| CR-AC-15 | 用户撤销 | 在对象read过程中撤销，后续块不输出；新读取/解析及旧请求ID拒绝；原片/SQL保留。 |
| CR-AC-16 | 用户删除任务 | 任务删除与码生成/替换/管理员读并发，授权和列表同时失效，旧码不能复活。 |
| CR-AC-17 | 多条请求 | 同时间戳和不同时间、稳定ID、分页以及重新生成重排；不改变WorkerFIFO。 |
| CR-AC-18 | 管理员删除请求 | 请求删除重复投递及与重新生成竞争，旧码/ID拒绝；源任务、摘要/对象和新请求不被误删。 |
| CR-AC-19 | 多用户并发 | 真实PG并发多用户创建，强制碰撞；复合外键和独立归属校验阻止错误关联。 |
| CR-AC-20 | 同任务并发重新生成 | 并发不同生成请求/相同幂等重传/事务失败，最多一有效授权，无半创建/列表残留。 |
| CR-AC-21 | 过期/撤销/替换码 | 到期/撤销/替换码和请求ID经两个入口、全部内容路径及重启验证；统一无效反馈。 |
| CR-AC-22 | 删除审计 | 读取审计和残留控制字段，无正文/文件名/有效凭证；按事件89/90/91天边界清理，不按任务起算或重试续期。 |
| CR-AC-23 | 列表权限 | 未登录/普通用户/停用管理员/撤销会话读取列表、解析、请求删除及内容路径受拒。 |
| CR-AC-24 | 备份功能移除后的删除 | 保留原删除/隔离/幂等/关联评测/代次/故障测试，确认移除产品功能未损害后台。 |

每行结果独立填通过/失败/未执行/不可评估及原因。参数化实例不是新增产品能力，HTTP拒绝与浏览器隐藏分别取证；页面移除不代表删除完成。

## 3. 补充故障与迁移规格

| ID | 验证内容 | 退出要求 |
| --- | --- | --- |
| CR-T25 | 旧目的授权含多目的/双范围/管理员自授权/撤销记录的合成升级；正式切换终止全部旧有效授权 | 不自动转码，不删除用户任务，旧purpose API无旁路，用户重新授权。 |
| CR-T26 | 生成已提交但响应丢失、幂等重传、并发替换、提交失败 | 重传不多建/续期；失败整体回滚；过期或替换的重传不能复活旧码。 |
| CR-T27 | 锁等待跨越到期、事务开始早于实际检查、服务重启/整理停用 | 实时后端期限权威，24h不延长，前端时钟不授予权限。 |
| CR-T28 | 码解析失败限速、API多进程/重启、异常事务、日志/URL/浏览器存储 | 失败计数不因返回错误回滚；不枚举用户任务，不泄露码/秘密；有效列表直接显示不取消认证。 |
| CR-T29 | 密文损坏、换行/非法编码、错误或缺失密钥、轮换 | 拒绝而不回退旧purpose/明文；只有有效主体获展示，密文不能跨任务挪用。 |
| CR-T30 | 清理临时/持续/危险故障，部署者诊断与再推进、无人工产品页 | 按WP01批准参数退避/限频；持久信号确实可发现；危险删除停止；操作归属/权限/审计/完成验证不可绕过。 |
| CR-T31 | 历史BACKUP/快照合成夹具、未知归属、对象版本及获准恢复 | 保留必要受控能力，不因取消备份把未知副本标完成；恢复不复活内容/会话/新旧授权。实际历史清理不由本测试授权。 |
| CR-T32 | 迁移重放/旧版本兼容、外键清除顺序、版本切换失败/回退 | 001～009校验不改；无双有效码/双权威状态；回退不能重新开放无限期授权。 |
| CR-T33 | 删除审计事件起算、作业超过90天仍未完成、完成后残留收缩 | 到期审计删除；必要执行控制单独标未完成并保留至完成/授权解决，不保存无必要内容，不虚报成功。 |
| CR-T34 | S3-12备份/自动快照配置核实与软件重建 | 无新主动内容备份，重建资料无用户内容；历史处置有专项批准/证据，明确不可恢复风险，不承诺物理擦除。 |
| CR-T35 | 错误对象键关联、未知目录/路径、跨任务清理、共享存储 | 不删除他人对象/目录；仅可信任务登记和受控路径，错误归属停止，不整bucket清空。 |

## 6. 新基线人工验收（实施后才可执行）

| 检查 | 通过条件 |
| --- | --- |
| 页面退出 | 两角色无删除记录，管理员无人工清理/备份核验，正常任务删除确认保留。 |
| 管理员自己的任务 | 我的任务无排障授权；我的任务/元数据页都能直接查看自己内容，无码。 |
| 三范围 | 普通用户无需purpose/密码，生成后看到码、范围、服务端过期时间和撤销；摘要双语JSON可用但视频拒绝，视频反向隔离，两者均可。 |
| 队列 | 无需通知自动入独立列表，码直接显示并可复制，只列有效普通用户请求，创建时间/ID排序正确。 |
| 精确定位 | 输入码仅一任务，列表进入同样授权；改目标不能越权。 |
| 生命周期 | 重生旧码失效/新时间重排，用户撤销及管理员删请求后不能再读取；源任务保留。 |
| 到期 | 后端到期拒绝，页面不显示为仍可访问；自动化覆盖准确边界，人工不修改业务库造时钟。 |
| 删除 | 仅用获准新建合成任务；接受后消失/拒绝，后台确实清理才完成；任务删除使授权退出。 |
| 诊断 | 仅隔离合成故障按已审方案检查信号、重试、受控诊断/再推进；不破坏真实存储造故障。 |
| 重启/隔离 | 原期限和失效状态不重置，另普通账户不能看他人码/任务或列表。 |
| 切换 | WP07专项验证旧授权统一终止，原任务保留，重新授权生效，旧API无旁路。 |
| 边界说明 | 下载/供应商/基础设施历史字节限制及无内容备份的不可恢复风险明确，不声称介质擦除。 |

## 7. WP01具体设计与独立审核补充

以[共享契约C0.3](CR-WP01_CONTRACT.md)、[A/B设计](CR-WP01_DATA_API_DESIGN.md)、[C删除运维](CR-WP01_DELETION_OPERATIONS.md)、[D迁移回退](CR-WP01_CUTOVER_ROLLBACK.md)为后续测试输入。S2从AC/E2E独立提出不变量矩阵、B1～B10交错和S2-F01～07；S3另独立审查，见[安全记录](CR-WP01_SECURITY_REVIEW.md)。最终关闭状态和待批参数见[评审报告](CR-WP01_REVIEW_REPORT.md)。

补充执行规格：
- 生成CREATE/REGENERATE+expectedID、全体绑定幂等；成功回执在task锁内计5分钟滚动预算。旧ID/旧key重放不能续期。
- DB时钟跨期锁/提交暂停与86400秒，不能只用tasks.utcnow假时钟。
- token过期且I/O仍在、父SIGKILL子仍活/pass_fds、锁inode替换、生产DB→SH反向锁负例；逐资产/进程/目录/SQL独立oracle。
- 清理§4.1持久字段/旧状态转换和n复位语义，60秒最小物理轮次、预算续轮、CLI/重启均不能重置first_requested_at或冒充成功。
- 密钥丢失后owner无缓存ID仍能查询无码Meta/CODE_UNAVAILABLE并撤销/重生；维护轮换排空与key SHARE/退役UPDATE，nonce废号不回滚/复用。
- 同用户不同task候选交换、immutable定位普通角色更新拒绝及合成旧登记回填一致；不要求应用防宿主root同时改全部权威映射。
- 受限ops角色、回执优先CAS、调度/回执/审计提交失败全回滚，无任意key/path/force；M3显式维护而非普通schema迁移自动终止授权。
- online/overall/unknown基础设施核实分开，登记BACKUP未清不能overall成功。

参数当前只是提案，测试须按最终产品审批值冻结，再在对应包授权后编写/执行。现有S3-10报告/JSON不得改写为新需求通过。
